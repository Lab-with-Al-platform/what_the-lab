# Data

개발과 테스트에 필요한 샘플 데이터 및 데이터 설명을 관리합니다.

## 허용

- 팀이 만든 가상의 사용자·프로젝트 데이터
- 개인정보를 제거한 테스트 픽스처
- 필드 정의와 데이터 사전

## 금지

- 실제 연구 원자료
- 이름, 전화번호, 이메일 등 실제 개인정보
- 라이선스가 불분명한 외부 데이터
- `.env` 또는 API 키

샘플 데이터에는 `sample`, `fake`, `fixture`처럼 용도를 알 수 있는 이름을 사용합니다. 초보 팀원이 전문가 목록·상세를 개발할 때도 실제 인물 대신 가상 프로필을 사용합니다.
