# Tests

저장소 전체의 통합·E2E 테스트와 공통 테스트 자료를 관리합니다. 프론트엔드와 백엔드의 작은 단위 테스트는 각 영역 가까이에 둘 수 있습니다.

## 우선 검증할 핵심 흐름

1. 회원가입·로그인과 역할별 접근
2. 프로젝트 등록·공개·탐색
3. 전문가 참여 신청
4. 연구자 협업 요청
5. 선택된 사용자만 프로젝트 멤버가 되는지
6. 마일스톤·종료·양방향 평가
7. 비멤버의 비공개 정보와 연락처 접근 차단

## 테스트 원칙

- 가상·비식별 데이터만 사용합니다.
- 정상 흐름과 실패 흐름을 함께 확인합니다.
- 테스트는 서로 실행 순서에 의존하지 않게 만듭니다.
- 고친 버그에는 같은 문제가 다시 생기지 않도록 회귀 테스트를 추가합니다.
