# Infra

로컬 개발, CI, 배포에 필요한 설정을 관리합니다.

## 범위

- 개발용 컨테이너 또는 Compose 설정(팀 합의 후)
- CI 검사 설정
- 배포 설정과 운영 절차 문서
- 환경별 설정 예시

## 개발 환경과 브랜치의 차이

- `develop`: 코드를 통합하는 Git 브랜치
- `development`: 로컬·공용 개발 실행 환경
- `main`: 안정 코드 브랜치
- `production`: 실제 서비스 실행 환경

브랜치 이름만으로 자동 배포하지 말고, 배포 대상과 승인 규칙을 명확히 정한 뒤 연결합니다.

## 보안

- 실제 비밀값을 파일에 저장하지 않습니다.
- 서버 전용 키를 프론트엔드 빌드 변수로 전달하지 않습니다.
- 로그에 토큰, 연락처, 연구 민감 정보를 남기지 않습니다.
- 운영 설정을 바꾸는 PR에는 영향과 되돌리는 방법을 적습니다.
