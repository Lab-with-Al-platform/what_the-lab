# AI

AI 추천·실험 코드를 위한 경계입니다.

## 현재 단계

개인화 AI 추천은 현재 MVP가 아닙니다. MVP 핵심은 두 매칭 경로와 실제 협업 완료 흐름입니다. 따라서 팀 합의 전에는 모델 학습, 벡터 검색, 외부 AI API 의존성을 추가하지 않습니다.

## MVP+ 이후 후보

- 구조화 필드 기반 규칙 추천
- 프로젝트 ↔ 전문가 적합 이유 설명
- 추천 평가용 오프라인 실험

실험을 시작할 때는 입력 데이터, 기대 출력, 평가 기준, 비용, 개인정보 처리 여부를 먼저 문서화합니다. 생성형 AI가 만든 결과는 사실로 단정하지 않고 사용자가 검토할 수 있게 합니다.
