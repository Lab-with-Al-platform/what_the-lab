# Design

Figma에서 전달한 화면 기준, 디자인 토큰, 내보낸 자산을 관리합니다.

## 관리 원칙

- 원본 Figma 링크와 최종 반영 버전을 함께 기록합니다.
- 이미지 파일은 목적을 알 수 있는 이름을 사용합니다.
- 같은 자산을 여러 이름으로 중복 저장하지 않습니다.
- 화면 구현과 디자인이 다르면 임의로 한쪽을 정답으로 정하지 않고 팀 합의를 남깁니다.

## 공통 화면 원칙

- 목록 카드와 상세 화면의 정보량을 구분합니다.
- 상태는 색상과 텍스트를 함께 사용합니다.
- 모든 상세·관리 화면에 다음 행동을 분명히 보여줍니다.
- 일부 공개 프로젝트는 목록 정보와 권한 승인 후 정보를 구분합니다.
- 용어는 `협업 요청`, `참여 신청`, `프로젝트 확정`, `마일스톤`, `양방향 평가`로 통일합니다.
