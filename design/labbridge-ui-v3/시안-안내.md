# LabBridge UI 시안 v3

기존 v2를 보존하고, 연구 협업 사례와 AI 트렌드 상세 화면을 추가했습니다.

## 포함 화면

- AI 연구 협업 사례 목록 / 상세
- AI 트렌드 목록 / 상세
- AI 전문가 목록 / 상세
- 각 화면의 PC·모바일 이미지, 총 12장

`labbridge-ui-v3.html`을 브라우저로 열면 상단에서 화면과 기기를 선택할 수 있습니다.
목록의 제목 또는 읽기 버튼으로 상세 화면을 열 수 있습니다.

## 상세 디자인

PC는 왼쪽 목차, 가운데 본문, 오른쪽 관련 정보의 3열 구조입니다.
태블릿 폭에서는 참고 정보를 본문 아래로 옮기고, 모바일은 1열로 배치합니다.
모바일은 이미지 → 제목·메타 정보 → 핵심 요약 → 접히는 목차 → 본문 → 관련 정보 순서입니다.

화이트·네이비·퍼플, 고딕 계열 한글 글꼴, 얇은 테두리와 연한 보라색 요약 영역을 사용했습니다.
과도한 장식과 기존 프로젝트 관리·정산 기능은 넣지 않았습니다.

## 검증과 범위

격리된 Chromium 브라우저에서 6개 화면의 PC·모바일 스크린샷을 만들고 직접 검토했습니다.
추가 상세 화면은 320·390·736·1024px에서도 가로 넘침 없이 배치되는지 확인했습니다.
목록 연결, 목차 선택·이동, 모바일 목차 접기, 저장, 기술 설명 펼치기,
목록 복귀와 관련 전문가 필터 연결을 검사했습니다.

이 결과물은 UI 시안입니다. 연구 콘텐츠, 인물, 날짜와 자료 항목은 예시이며,
실제 서비스의 논문 출처 검증·계정·데이터 저장·협업 요청 전송은 연동하지 않았습니다.
모바일 목차에 sticky 스타일을 적용했지만 대화창의 외부 스크롤 방식에 따라
미리보기에서 고정되는 동작은 실제 서비스 브라우저와 다르게 보일 수 있습니다.

`screens/`에는 전체 페이지 PNG가 있습니다. `*-top.png`는 상세 화면 상단 검토용입니다.
