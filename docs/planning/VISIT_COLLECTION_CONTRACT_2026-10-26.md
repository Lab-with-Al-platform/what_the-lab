# 방문·등록 수집 계약 — 2026-10-26

3단계 수집의 식별·보관·거부입니다. 수집 스위치는 꺼 둔 상태이고, 원격 데이터베이스에는 표를 적용하지 않았습니다. 방문 통계 화면은 4단계입니다.

## 이번에 정한 것

| 항목 | 결정 |
|---|---|
| 세션 | 브라우저 탭의 임의 번호. 30분 동안 기록이 없으면 새 번호. 페이지 방문과 글을 읽은 세션에만 사용 |
| 방문자 수 | 만들지 않음. 세션 수는 사람 수가 아님 |
| 계정 연결 | Discord, 이메일, 로그인 쿠키, 회원 번호를 분석 기록에 넣지 않음 |
| 보관 | 원본과 일별 횟수를 남김. 자동 삭제는 하지 않음. 기간은 나중에 정함 |
| 고유 세션 | 고른 기간의 원본에서 세션 번호를 셈. 하루 고유 수를 더해 주·월 고유 수로 만들지 않음 |
| 거부 | 스위치 기본값 꺼짐. 관리자·미리보기·localhost는 브라우저가 보내지 않거나 서버가 제외. 공개 거부 버튼은 이번에 만들지 않음 |
| 등록 완료 | 연구가 처음 등록으로 저장될 때 서버가 기록. 버튼 클릭만으로는 완료가 되지 않음 |
| 기존 연구 수정 | 신규 등록 완료에 포함하지 않음 |

원본을 나중에 지우면 그 기간의 고유 세션 수는 다시 계산할 수 없습니다. 일별 횟수 표는 조회수·클릭 수처럼 더할 수 있는 값만 담습니다.

## 수집하는 사건

- 공개 페이지 표시: 홈, 사례 목록, 트렌드 목록, 전문가 목록, 각 상세의 종류
- 공개 글 조회: 정적 목록에 있는 유형과 slug. 글을 읽은 세션은 여기에 세션 번호를 붙임
- 전문가 탐색 클릭, 관련 글 이동: 횟수만 기록. 세션 번호는 붙이지 않음
- 연구 등록: 창 열기, 단계 표시, 다음 이동, 검증 실패 코드, 임시저장 성공·실패, 닫기, 선택 사유, 서버의 최초 등록

등록 사건에는 세션 번호를 넣지 않습니다. 작성 시도 번호로만 같은 창의 단계를 묶습니다. 연구 제목·설명·연락처·주소의 검색어는 보내지 않습니다.

닫기 기록이 없다고 해서 등록에 성공한 것은 아닙니다. 창을 그냥 닫은 사람은 사유가 비어 있을 수 있고, 그 사유를 채워 넣지 않습니다.

## 아직 하지 않은 것

- `ANALYTICS_COLLECTION_ENABLED`를 켜기
- 원격 표 `20261026_09` 적용. 그 앞의 조회수 표·운영 이력 표도 아직 원격에 없습니다
- 방문자 수, 체류 시간, 유입 전체 주소, 기기 지문
- 수집 스위치를 켜거나 원격 표를 적용한 뒤의 실제 방문 수. 방문 통계 화면은 연결했지만 수집 전·표 없음이면 숫자를 만들지 않습니다
- 전문가 탐색 클릭을 협업 확정으로 세기

기존 공개 글 조회수(`INSIGHT_VIEWS_ENABLED`)는 그대로 별도입니다. 그 스위치도 꺼져 있습니다.
