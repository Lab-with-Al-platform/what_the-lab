# 협업 요청 관리 경계 (2026-10-26)

5단계는 있는 협업 모듈만 연결합니다. 연구 등록 행에 진행 상태를 만들어 넣지 않습니다.

## 연결된 것

`collaboration_request`의 현재 상태만 읽습니다.

- 답변 대기, 전문가 수락, 협업 시작, 거절, 기한 만료, 취소
- 기간에 새로 생긴 요청 수. 이전 기간과 비교할 수 있지만, 시작 수를 요청 수로 나눈 성공률은 없습니다.
- 목록은 요청 번호, 연구 제목, 등록자 닉네임, 전문가 닉네임, 상태, 생성·응답·시작 시각만 보여 줍니다.

관리자는 요청을 수락·거절·시작·취소할 수 없습니다. 메시지, 수락 한마디, 거절 사유와 문구는 가져오지 않습니다.

## 연결하지 않은 것

참여 신청, 마일스톤, 완료, 양방향 평가 표는 없습니다. 화면은 연동 전이고 값은 null입니다.

연구 목록의 진행 상태는 계속 연동 전입니다. 협업 시작 요청이 있어도 그 연구를 진행 중이나 완료로 바꾸지 않습니다.
