# 홈 소개 영상 후속 작업 인계

작성일: 2026-10-30. 사용자 요청을 보관한 계획 문서입니다. **영상 재생·방문 기록 기능은 아직 구현하지 않았습니다.**

## 이번에 확정한 범위

- 먼저 메인 상단에 기존 LabBridge 소개, 플랫폼 이용 안내, Discord 이용 안내의 세 화면을 만듭니다.
- 두 안내는 요약·소개만 제공합니다. 상세 매뉴얼은 다른 팀원이 작업하며, 링크는 아직 없습니다. 상세 내용은 FAQ에 생길 예정입니다.
- 미정 URL·가짜 링크·동작하지 않는 상세 버튼을 만들지 않습니다. 현재는 ‘상세 매뉴얼 준비 중’ 텍스트만 표시합니다.
- 플랫폼 이용 안내: 인사이트 → 전문가 찾기 → 협업 매칭 → 프로젝트 진행. 협업 요청 → 검토·협의 → 프로젝트 확정을 보조 문구로 설명합니다. 인사이트 열람이 협업의 필수 선행 조건이라는 뜻은 아닙니다.
- Discord 이용 안내: 프로젝트 대화·협업의 실제 사용 공간이라는 콘셉트에 챗봇과 Google Calendar 연결을 시각화합니다. 화면은 연결 구조 예시이며 실제 메시지·연동 상태 조회가 아닙니다. 외부 API·채널 생성·일정 전송·챗봇 호출은 추가하지 않습니다.

## 영상 관련 최신 사용자 요구사항

이전 ‘최초 한 번’ 제안보다 **이번 ‘하루 주기로 첫 방문’ 요청이 우선**합니다.

- 소개 영상은 약 1분(초안 목표 55초).
- 하루의 첫 방문 때 한 번 자동재생을 시도하고, 이후에는 일반 소개·안내 화면을 순환합니다.
- 일시정지/재개, 건너뛰기, 다시 보기, 소리 켜기/끄기, 자막을 제공합니다.
- 영상 시청 중에는 슬라이드 넘김 타이머가 작동하지 않습니다. 9초짜리 일반 배너 타이머로 영상을 넘기면 안 됩니다.
- 영상 종료·건너뛰기 뒤에는 현재 소개 화면부터 일반 순환으로 돌아옵니다.
- 다시 보기는 당일 재생 기록과 관계없이 사용자가 실행할 수 있습니다. 일반 순환 항목에 영상을 넣어 매번 자동 반복하지 않습니다.

## 다음 작업 시작 시 확인할 기준

아래는 구현 제안이며, 아직 사용자와 확정하지 않은 정책입니다.

1. ‘하루’는 Asia/Seoul의 달력 날짜(00:00에 새 날짜) 기준을 제안합니다. 마지막 재생 후 24시간이 지나는 방식과는 다릅니다. UTC `toISOString()`의 날짜만 잘라 한국 날짜로 쓰지 않습니다.
2. 우선 같은 브라우저·같은 사이트 기준을 제안합니다. `localStorage`에 버전·재생일만 기록하고 계정 ID·연구 정보·방문 통계를 붙이지 않습니다. 계정별/기기 간 동기화는 별도 결정과 서버 계약이 필요합니다.
3. 기록 시점은 실제 `playing` 이벤트 또는 명시적 건너뛰기를 제안합니다. 단순 마운트·로딩·실패를 시청으로 기록하지 않습니다. 부분 시청 후 당일 재방문 정책은 이 기록 시점으로 결정됩니다.
4. 소리 있는 자동재생은 브라우저가 차단할 수 있습니다. `muted`, `playsInline`을 기본으로 두고 수동 재생 버튼과 소리 켜기를 제공합니다. 무음도 차단되면 썸네일로 대체합니다.
5. 저장소 접근 거부·시크릿 모드·저장 기록 삭제·브라우저 변경 시 매일 한 번을 보장할 수 없습니다. 오류 시 홈 이용을 막지 않는 대체 흐름을 정합니다. 탭 두 개의 동시 첫 방문도 테스트합니다.
6. `prefers-reduced-motion`, 데이터 절약, 백그라운드 탭 및 화면 밖 이동 시 재생/자동재생 정책을 정합니다. 사용자가 직접 멈춘 영상은 복귀 시 임의 재개하지 않습니다.
7. 자정에 페이지를 열어둔 사람에게 갑자기 영상을 띄우지 않습니다. 다음 홈 진입에서 새 날짜 여부를 확인하는 방식을 제안합니다.

## 상태와 책임을 먼저 나눌 것

- 홈 배너: `frontend/src/components/home-hero.tsx`. 현재 일반 소개·안내 전환만 담당합니다.
- 안내 그래픽: `frontend/src/components/home-guide-visuals.tsx`.
- 기존 연구 사진: `home-page.tsx`에서 ReactNode로 전달합니다. 사진 최적화와 공통 프레임을 유지합니다.
- 후속 영상 컴포넌트: 재생 중/일시정지/완료/실패와 음소거 상태 담당. 실제 작업 시 필요한 경우에만 분리합니다.
- 하루 노출 판단: 날짜와 저장 기록 판단을 순수 함수로 먼저 테스트한 뒤 브라우저 저장을 연결합니다. 분석 수집 코드와 섞지 않습니다.
- 향후 매뉴얼 링크: 팀원이 전달한 실제 URL·공개 여부를 확인한 뒤 준비 중 텍스트를 링크로 교체합니다. FAQ 본문을 이번에 대신 작성하지 않습니다.

## 영상 제작 초안

실제 동작을 검증한 화면을 데모 계정으로 녹화하고, 짧은 자막·내레이션을 붙입니다. 개인정보·실제 연구 데이터·Discord 비공개 메시지·초대 링크·토큰을 촬영하지 않습니다. 배경음·음성·이미지의 이용 권한을 확인합니다.

| 시간 | 메시지·소재 |
| --- | --- |
| 0~5초 | ‘내 연구에도 AI를 활용할 수 있을까요?’ |
| 5~12초 | 로고와 플랫폼 핵심 소개 |
| 12~24초 | 인사이트에서 연구 아이디어 발견 |
| 24~36초 | 함께할 전문가 탐색 |
| 36~47초 | 검증된 협업 흐름과 Discord 활용 소개 |
| 47~55초 | ‘연구의 다음 가능성, LabBridge에서 시작하세요.’ |

- 웹용 가로 16:9와 외부 홍보용 세로 9:16을 각각 배치합니다. 하나를 강제로 잘라 사용하지 않습니다.
- 웹용 MP4(H.264/AAC를 초기 후보로 검토), 대체 포스터 이미지, 자막·대본, 편집 원본을 함께 보관합니다.
- 한국어 자동 자막은 사람이 검수합니다. 무음 상태에서도 핵심 메시지가 이해되어야 합니다.
- 기본 파일은 가볍게 인코딩하고 일반 순환만 보는 방문자에게 영상 전체를 미리 내려받지 않습니다. 실제 용량·화질·로딩 시간은 완성 영상으로 검증합니다.
