# LabBridge 디자인 충실도 QA 및 PR 체크리스트

> 이미지가 멋있어도 실제 구현 화면의 디테일이 떨어지는 문제를 막기 위한 **검수 절차**. 정적 시안과 실제 인터랙션 검증은 별도이다.

## 1. 비교 조건

- 기준 파일: `design/AI 연구 플랫폼 랩브리지 랜딩페이지.png`, `design/LabBridge 암세포 분석 연구 페이지.png`.
- 실제 브라우저 캡처: **1440×900 / 768×1024 / 390×844**, 100% 줌. 모바일은 실제 기기 또는 모바일 브라우저 에뮬레이터도 확인.
- 기준 이미지의 원본 크기/비율이 캡처와 다르면 **동일 너비로 정규화**하여 비교하고, 비율 차이로 생긴 크롭을 결함으로 오판하지 않는다.
- 폰트 로딩 완료, 동일 데이터, 같은 스크롤 위치, 같은 로그인 상태에서 비교. 스켈레톤이 사라진 후 캡처.
- **기준과 다른 화면(목록/전문가)은 P0의 공통 요소만 비교**하고 구조는 해당 보조 시안과 비교. 시안 픽셀을 무조건 일치시키려 하지 않는다.

## 2. 검수 순서 (앞 단계가 실패하면 디테일 조정 전에 수정)

### A. 정보 구조·레이아웃
- [ ] 랜딩 상단 내비/히어로/3개 탐색 카드/최신 인사이트/인터뷰 순서가 맞음
- [ ] 헤더·콘텐츠·푸터의 좌우 정렬선이 통일됨
- [ ] 랜딩의 인사이트와 인터뷰 비율이 적절하며 카드 하단 정렬이 일치함
- [ ] 상세 PC 3열과 모바일 1열 전환, 오른쪽 패널의 이동 순서가 맞음
- [ ] 화면 가로 스크롤, 레이아웃 점프, 내용 가림이 없음

### B. 타이포그래피·콘텐츠 밀도
- [ ] 웹폰트·두께·글자 간격·행간이 기준과 유사함
- [ ] H1 줄바꿈이 의도와 맞고 카드 제목 2행·요약 2~3행이 안정적임
- [ ] 메타·캡션·태그의 시각적 위계가 명확함
- [ ] 빈칸을 채우려고 근거 없는 연구 결과/기관/수치를 만들지 않음

### C. 이미지·그래픽
- [ ] 랜딩 연구×AI 합성 이미지의 핵심 소재와 레이어 구조를 재현함
- [ ] 카드 배경 이미지의 오버레이와 텍스트 대비가 적절함
- [ ] 목록 카드 썸네일의 크롭/비율/해상도가 통일됨
- [ ] 연구 도판은 중요한 정보가 잘리지 않고 캡션/출처가 있음
- [ ] 이미지 원본, 사용 허가, alt, 파일명, 용도를 기록함

### D. 디테일
- [ ] CTA 보라색과 링크/활성 탭 색이 공통 토큰에서 나옴
- [ ] radius, border, shadow, 패딩, 칩 높이, 아이콘 크기가 컴포넌트 간 일관됨
- [ ] hover/focus/active/disabled/loading 상태를 확인함
- [ ] 라이트 배경에서 충분한 대비, 최소 터치 영역 44px을 확보함

### E. 모바일 TOC 스크롤 동작 (실제 조작 필수)
- [ ] 처음에는 본문 속 원래 위치에 있음
- [ ] 헤더 아래 도달 시에만 sticky로 전환됨
- [ ] 접힌 상태에 현재 읽는 섹션명이 표시됨
- [ ] 펼치기/접기와 키보드·스크린리더 상태가 정확함
- [ ] 항목 선택 후 본문 이동, 자동 접힘, 활성 섹션 갱신
- [ ] 섹션 제목이 헤더/TOC에 가려지지 않음
- [ ] 위로 스크롤 시 원래 위치로 자연스럽게 복귀
- [ ] 본문 종료 시 sticky가 푸터를 덮지 않음

### F. 기능·MVP 경계
- [ ] 시안에 보이는 버튼이 실제 구현 범위인지 문서 확인
- [ ] 인사이트/저장 등 MVP+ 기능을 MVP 완료로 잘못 표시하지 않음
- [ ] 가짜 DOI·성능·인증·리뷰·북마크 상태를 실제 데이터처럼 노출하지 않음
- [ ] 로딩·빈 목록·오류·재시도·필터 초기화 확인

## 3. PR에 붙여 넣는 검수 기록

```md
## 디자인 참조
- P0 기준 이미지: (파일명/링크)
- P1 구조 참조: (파일명/링크, 해당 시)
- 화면 승인 상태: Approved / Review / Proposed

## 캡처 비교
| 폭 | 기준 이미지 | 구현 이미지 | 차이 | 수정/미확정 |
|---|---|---|---|---|
| 1440 | 링크 | 링크 | | |
| 768 | 링크 | 링크 | | |
| 390 | 링크 | 링크 | | |

## 검증
- [ ] 헤더·레이아웃·정렬
- [ ] 타이포·콘텐츠 밀도
- [ ] 이미지 원본·크롭·출처
- [ ] 색·그림자·반경·상태
- [ ] 모바일 TOC(상세 페이지)
- [ ] 접근성·오류·빈 상태
- [ ] MVP 범위·미확정 항목 확인

## 실제 실행
- lint: (명령/결과 또는 미실행 이유)
- typecheck: (명령/결과 또는 미실행 이유)
- test: (명령/결과 또는 미실행 이유)
- build: (명령/결과 또는 미실행 이유)
```

## 4. 승인 원칙

- **치명적 차이**: 헤더/컨테이너 불일치, 연구×AI 히어로 누락, 상세 3열 구조 붕괴, 모바일 목차 오류, 허위 콘텐츠 → 수정 전 승인 불가.
- **수정 권장**: 미세한 그림자/색 차이, 작은 아이콘 위치 편차, 세부 간격 → 수정 기록 후 재검토.
- P0에 없는 새 장식은 임의 추가하지 않는다. 미확정 컴포넌트는 팀 검토 후 `STYLE_GUIDE.md`를 먼저 업데이트.
