# 메인 플랫폼 이용 안내 FAQ 연결

검증일: 2026-11-10 (한국시간)

## 변경과 동작

- 플랫폼 이용 안내 슬라이드의 준비 문구를 `플랫폼 이용 안내 FAQ →` 링크로 교체했습니다.
- 목적지는 `/faq?category=workspace`입니다. 배포 사이트에서는 사용자가 지정한 `https://what-the-lab.vercel.app/faq?category=workspace`가 됩니다.
- `slide.id === "platform"` 조건이 플랫폼 화면에만 버튼을 표시합니다.
- `Link`의 `href`는 이동 주소, `home-hero__cta`는 기존 보라색 버튼 스타일입니다. 페이지 이동에는 링크를 사용하는 기존 규칙을 따릅니다.
- 기존 소개 CTA와 Discord 준비 문구, FAQ 본문은 유지했습니다.

## 화면 비교

P0 랜딩 이미지와 사용자가 첨부한 현재 플랫폼 안내 화면을 참고했습니다. 네이비 제목·보라 CTA·기존 사진과 반응형 배치를 재사용했으며 새 CSS는 추가하지 않았습니다.

## 검증 경계와 학습 힌트

로컬 프로덕션 빌드를 브라우저에서 확인했습니다. 운영 배포, 커밋, push는 하지 않았습니다. 실제 휴대전화·다른 브라우저·스크린리더·키보드만을 사용한 이동은 별도 검증하지 않았습니다. 기존의 관련 없는 작업 파일은 수정하지 않았습니다.

학습 힌트: 주소의 `category=workspace`를 빼면 어떤 분류가 처음 선택될지 FAQ의 `params.get("category")` 부분과 연결해 생각해 보세요.
