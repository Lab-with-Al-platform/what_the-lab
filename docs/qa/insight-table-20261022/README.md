# 인사이트 관리자 — 6개 컬럼 표와 게시글 기준 필터

2026-10-22 사용자 후속 요청을 반영했습니다. 제목만 남긴 중간안을 대체하는 최신 화면입니다. 주소: `http://localhost:3000/admin/insights` (실제 관리자 로그인 필요).

## 구현한 내용

1. 제목 → 상태 → 유형 → 연구 분야 → 키워드 → 등록·수집일 순서의 표. 48px 높이로 6건씩 표시하고 요약·표지·긴 원고는 기존 모달에서 봅니다.
2. 제목 버튼과 행의 빈 공간을 클릭하면 동일 편집 모달을 엽니다. 제목 버튼은 키보드로도 접근할 수 있습니다. 긴 제목·분야·태그는 한 줄 말줄임과 툴팁, 전체 내용 모달을 사용합니다.
3. 상태는 ‘초안/검토 대기/승인됨/게시 중’을 텍스트 배지로 표시하고, 수정본이 있으면 ‘게시 중’과 ‘수정 초안/검토 대기’ 등을 함께 표시합니다. 키워드는 2개와 `+N`이며 전체 라벨은 툴팁으로 확인합니다.
4. 등록·수집일은 한국 시간 기준 `YYYY.MM.DD`입니다. 원 논문 발표일·원 게시일과 다르며 정확한 등록 시각은 툴팁에서 확인합니다.
5. 중복된 원고 구분 선택 상자를 제거하고 전체/후보/게시글 사이드 메뉴를 유일한 조회 범위로 사용합니다. 유형·상태·분야·키워드·정렬 5개 필터와 텍스트 검색·초기화를 유지합니다.
6. 분야·키워드 선택지는 Publication의 **현재 공개 스냅샷**에서만 구성합니다. 기존 원고의 article.field/tags와 새 게시 API의 research_field/승인된 keywords 형태를 모두 처리합니다. 원고 본문 전체를 추가로 읽지 않고 분류 JSON 조각만 조회합니다.
7. 미게시 후보, 미게시 수정본과 용어 사전의 모든 항목을 분류 선택지에 넣지 않습니다. 후보 자체는 계속 보이며 후보 고유 키워드도 텍스트 검색이 가능합니다. 게시글이 하나도 없으면 두 분류 필터는 ‘모든 값’ 외에는 비어 있습니다.
8. 표의 원고 값은 현재 작업 판본, 필터 선택지는 공개본이라는 경계를 유지합니다. 수정 초안에서 분야/태그를 바꾸면 재게시 전까지 선택지에 반영되지 않으며, 기존 공개 분류를 선택했을 때 수정 중인 행이 일치하지 않을 수 있습니다. 공개본을 대신 수정하는 동작은 없습니다.
9. 버튼·입력·사이드 메뉴·접힌 필터를 간결하게 정리했습니다. PC 버튼/입력 높이 36px, 터치 기기는 44px. 공통 CSS 색 토큰을 사용하고 모바일·태블릿은 표 내부만 가로 스크롤합니다.

## 핵심 흐름 — 학습용

- `published_facets()`: 게시 스냅샷 → 분야와 태그/승인 라벨만 추출 → 중복 제거 → 정렬. 현재 후보나 수정본에서 선택지를 가져오지 않으므로 미게시 분류가 먼저 나타나지 않습니다.
- `InsightAdminWorkspace`: 별도의 scope 상태를 없애고 메뉴에서 범위를 계산합니다. 같은 목적의 메뉴와 필터가 서로 다른 상태가 되는 실수를 줄였습니다.
- `InsightWorkspaceTable`: 목록 표의 표시와 원고 선택만 담당합니다. 편집·저장·승인 로직을 표 안에 복사하지 않습니다.
- `formatAdminDate()`: 시간대를 한국으로 고정하고 연·월·일을 조립합니다. 기존 날짜 문자열을 공백으로 잘라 연도만 표시되는 오류를 피했습니다.
- `admin-ui.ts`: 버튼·입력 크기를 한 곳에서 바꿔 목록과 편집/설정/확인창의 모양을 맞춥니다. 접근 권한과 승인 조건은 변경하지 않습니다.

## 보존과 미검증

실제 글·회원·수집 설정·DB 스키마를 바꾸거나 실제 승인/게시·수집 실행·커밋/push/PR·운영 배포를 하지 않았습니다. 일반 공개 사이트의 정적 원고 경계도 유지합니다. 실제 Discord 로그인, 실제 휴대전화/Safari, 화면낭독기와 확대 배율별 완전 검증은 하지 않았습니다. 미리보기는 글 배치 확인용이며 실제 sticky 스크롤 전체를 에뮬레이트하는 도구는 아닙니다.
