# 수집 메모·게시용 원고 분리 및 6개 후보 설명 보강

확인일: 2026-10-22, 현재 `feature/insight-candidate-import` 작업본 기준.
기존 미커밋 작업을 보존했고 이 작업으로 커밋·push·PR·배포하지 않았습니다.

## 해결한 원인과 변경

기존 공개 글 31개와 Supabase 공개 스냅샷은 전체 JSON이 정확히 일치했습니다.
짧았던 것은 새 후보 6개의 수집 메모(8개 주장, 본문 618~700자)였으며,
화면이 긴 글을 잘라낸 문제가 아니었습니다. 기준서 3.2의 설명 깊이가
게시용 원고·승인 검사로 연결되지 않았던 부분을 보완했습니다.

- `collection_note`와 `article_draft` 구분. 목록에 ‘수집 메모’ 또는 ‘게시용 초안’ 표시.
- 메모에서 별도 원고 틀을 만드는 API와 버튼 추가. 자동 집필·검증 완료·자동 승인이 아님.
- 긴 본문은 별도 판본으로 보존하며 짧은 메모 저장 API로 덮어쓸 수 없음.
- 전체 원고 편집에서 문단·용어를 추가할 수 있고 빈 문단은 저장 거절.
- 쉬운 해설·적용 예시·주의 문단과 용어 풀이의 구조 누락 검사.
- 최종 승인 요청에 독자 검수 6항목을 추가. 글자 수를 게시 자격 기준으로 사용하지 않음.
- 근거 확인·출처·점수·키워드·권리 검사 및 트렌드 승인 차단은 유지.
- 원고를 저장하면 기존 승인이 무효이며 재조회 후 UI 체크도 초기화.
- 첫 게시 때도 승인된 전체 원고를 공개 API 스냅샷에 포함. 기존 공개본 정정 절차는 유지.
- 이미지 없는 원고에 빈 칩 배열 때문에 사진 캡션이 붙던 표시 문제 수정.

## 원문과 해설의 경계

원문의 사실 메모를 보존하고 추가한 작동 설명·비유·작은 시험은 편집자 해설·적용 제안으로
표시했습니다. 연구를 재현하거나 새 성능·비용·실제 조직 협업 실적을 만든 것이 아닙니다.
과거 연구를 최신 발표로 표시하지 않으며 각 원고에 확인 범위를 기록했습니다.

- [MIT 공식 Halicin 설명](https://news.mit.edu/2020/artificial-intelligence-identifies-new-antibiotic-0220): 공식 연구팀 설명 재확인. Cell 논문의 모든 실험 조건 대조·재현은 미실시.
- [DeepMind TCV 설명](https://deepmind.google/blog/accelerating-fusion-science-through-learned-plasma-control/), [Nature 논문](https://www.nature.com/articles/s41586-021-04301-9): 공식 설명과 검색 가능한 논문 내용 확인. 장치 제어·코드 실행 미실시.
- [Kepler 저자 공개 논문](https://arxiv.org/html/1712.05044v1): 방법·후보 검증 설명 확인. 광도 곡선 분석 재현 미실시.
- [RAG 원 논문 v4](https://arxiv.org/html/2005.11401v4): 방법·평가 구성 재확인. 현재 상용 도구 성능·보안·플랫폼 챗봇 연결 미검증.
- [컨포멀 예측 공개 튜토리얼 v6](https://arxiv.org/html/2107.07511v6): 기본 절차·가정·평가 설명 확인. 증명 검증·실행·분야별 시험 미실시.
- [TabPFN Nature 논문](https://www.nature.com/articles/s41586-024-08328-6): 검색 가능한 방법·평가·한계 설명 확인. 현재 패키지·가중치·라이선스·설치·실험은 별도 확인 대상.

## 삽화 운영 순서

본문 검토 → 삽화 준비 → 내용 일치·캡션·권리 확인 → 최종 승인 → 게시.
이미지가 필요 없으면 이미지 없이 진행할 수 있습니다. 원고 6개는 `no_image`이며
삽화를 아직 생성하거나 연결하지 않았습니다. 표지·권리 설명 변경은 현재 편집 API에서
보호하고 있으므로 이미지 연결·별도 권리 검수 화면은 후속 단계입니다.

- 백엔드 전체 115 passed / 1 skipped. 실제 PostgreSQL 동시 게시 검사는 전용 URL·실행 설정 미지정으로 생략.
- 프론트엔드 단위 검사 34개 통과. 빈 배열의 사진 캡션 회귀 검사 포함.

- 별도 빌드 폴더에서 Next.js 프로덕션 빌드 57개 페이지 생성 통과. 실행 중 개발 서버의 빌드 폴더를 사용하지 않음.
- 가상 관리자·임시 SQLite로 브라우저 검사 7개 통과: 전체 본문·출처 범위 / 이미지 없는 미리보기 / 1440·768·390 폭 / 웹·모바일 전환 / 검수 체크 초기화 / 용어·문단 추가와 빈 문단 차단 / 메모→원고 틀 전환.

실제 Discord 재로그인, 실제 회원 권한으로 승인·게시, 운영 배포, 자동 수집 실행,
유료 API, 삽화 생성, 논문 코드 재현은 수행하지 않았습니다.
기존 Starlette/httpx 경고와 기존 회원가입·계정 이미지의 빌드 경고는 이번 범위 밖입니다.
