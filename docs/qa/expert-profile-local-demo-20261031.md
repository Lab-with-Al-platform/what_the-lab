# 전문가 상세 전체 시연용 가상 데이터 — 로컬 개발 전용

작성일: 2026-10-31

## 목적
전문가 검색 화면에서 `프로필 보기`를 눌렀을 때, 실제 협업·평가·경력 데이터가 아직 없어도 사용자가 선택한 전문가 상세 시안의 **모든 섹션**을 검수할 수 있도록 합니다.

## 적용 범위
현재 브랜치 `feature/expert-search-dark-profile-first-20261031` 내 `frontend/src/lib/expert-local-demo.ts` 에서만 정의합니다.

| 가상 전문가 | 시연 데이터 |
|---|---|
| [데모] LLM 전문가 | RAG·LLM, 가상 완료 협업 3건, 후기 3건, 경력 2개, 학력 1개, 자격증 2개, 포트폴리오 3개(기존 로컬 DB 데이터 1개 + 가상 2개) |
| [데모] 의료 AI 전문가 | 의료영상·멀티모달, 위와 동일한 양, 시연상 '현재 협업 중' |
| [데모] 비전 전문가 | 컴퓨터비전·모델 검증, 위와 동일한 양 |
| [데모] 데이터 전문가 | 통계·데이터 품질·예측 분석, 위와 동일한 양 |

모든 가상 점수·후기·연구 이력은 `LOCAL DEMO` 및 `DEMO · 가상 평가`로 표시됩니다. 실제 사용자의 검증 평가처럼 노출하지 않습니다.

## 작동 방식 (안전 경계)
- `process.env.NODE_ENV === "development"`.
- 브라우저 주소가 `localhost` 또는 `127.0.0.1`.
- 백엔드에서 받은 전문가 `nickname`이 정확히 가상 4명 중 하나이고, `affiliation`도 기존 SQL의 특정 `시연용` 값과 정확히 일치.
- 모든 조건이 맞아야 클라이언트의 공개 프로필 응답을 **화면 표시용으로만 복제**하여 가상 평가·포트폴리오·경력·협업 기록을 추가합니다.
- 실제 API 응답 객체를 변형하지 않고, 데이터베이스 삽입·수정도 하지 않습니다.
- **개발 외 환경(프로덕션, Vercel 빌드, 타 도메인)에서는 전부 비활성화됩니다**.
- 시연용 협업 요청 클릭 시 기존 서버 API로 전송하지 않고 설명 모달을 표시합니다. 실제 전문가를 보면 원래의 요청 모달과 서버 API를 그대로 사용합니다.
- 가상 포트폴리오에 다운로드 링크·실제 PDF 파일은 없습니다.

## 이미 Docker에 4명을 넣었다면
**SQL 파일을 다시 실행할 필요가 없습니다.** 이 변경은 기존 로컬 DB에서 받아온 네 전문가의 상세 페이지를 시연용 정보로 보강하는 *프론트엔드 개발 전용 기능*입니다.

프로젝트 최상위 경로 PowerShell:
```powershell
git pull --ff-only https://github.com/Lab-with-Al-platform/what_the-lab.git feature/expert-search-dark-profile-first-20261031
```

백엔드 서버를 켜고(기존 DB/환경변수 필요):
```powershell
cd backend
uv run uvicorn app.main:app --reload --port 8000
```

별도 프로젝트 최상위 폴더 PowerShell에서:
```powershell
cd frontend
npm.cmd run dev
```

브라우저 주소: `http://localhost:3000/experts`.
목록에서 네 명의 `[데모]` 전문가 중 하나를 누르면 **LOCAL DEMO** 배너와 함께 각 상세 탭, 실적/후기, 도넛 그래프, 협업 조건, 버튼 미리보기가 나타납니다.

## 점검 체크리스트
1. 네 명 모두 `LOCAL DEMO` 배너 노출.
2. 이 서비스에서 한 연구·평가 탭 → 예시 평균 점수와 세부 지표, 가상 후기 3건, 완료 협업 3건 표시.
3. 포트폴리오 탭 → 기존 DB 시연 포트폴리오 1개 + 로컬 화면 전용 2개 표시.
4. 경력·학력·자격증 탭 → 경력 2개, 학력 1개, 자격증 2개 표시.
5. 우측 완료 연구 분야 도넛/협업 조건 표시. 의료 AI 전문가는 시연용 참여 중 상태 표시.
6. 가상 계정의 `협업 요청` 클릭 → 실제 전송 없이 설명 모달 표시.
7. 일반 전문가의 상세 프로필은 **가상 점수·이력 없이 실제 서버 데이터만 사용**.
8. 브라우저 390px/768px/1440px UI 및 키보드/모달 닫기 확인.
