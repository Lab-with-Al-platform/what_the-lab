## 무엇을 바꿨나

- 사례 15개·트렌드 13개의 기존 섹션에 글별 6~7개 문단을 추가했습니다. 목차를 늘리는 대신 데이터 준비, 쉬운 원리, 구체적 예시, 실패 조건, 작은 평가와 협업 산출물을 설명했습니다.
- 치주골·MatterGen 사례·MatterGen 트렌드 3개 본문과 Co-Scientist·AlphaEvolve의 기존 첫 6개 섹션은 보존 검사로 확인했습니다.
- 이전 작업의 전용 표지 18개, 31개 글의 고유 표지·URL·분류·목차 개수·용어 개수를 유지했습니다. 이번에는 이미지를 추가 생성하지 않았습니다.
- `expansion`은 ‘기존 섹션 ID → 추가 문단 목록’입니다. 조립 함수가 같은 ID의 섹션 뒤에 문단을 붙입니다. 원고와 표시 로직을 분리해 같은 문장을 여러 화면에 복사하지 않도록 했습니다.
- 원문에서 확인한 설명은 일반 본문, 이해를 돕는 설명·가정은 해석, 작은 시험은 적용 제안, 근거·범위의 한계는 주의 노트로 구분했습니다. 역할 분담 제안은 실제 저자별 업무 기록이 아닙니다.

## 검증

- 콘텐츠·표지·보존·출처·문단 유형·용어·명암 대비 테스트 **17개 통과**.
- Next.js 프로덕션 빌드 성공, 정적 페이지 **53개 생성**. 타입·린트 오류는 없었습니다. 기존 미사용 `nickname` 1건과 `<img>` 최적화 권고 4건은 남겼습니다.
- 상세 31개 × 1440/768/390px = **93개 조건**에서 응답·제목·섹션 수·이미지 로딩·가로 넘침 검사 통과. 브라우저 페이지 오류 0건.
- 홈과 사례·트렌드 목록의 각 3페이지에서 전용 표지 18개 연결 확인. 용어 click/Enter/Space, 모바일 역할 목차 이동과 접힘 확인.
- 실제 목차로 원리·작은 시험 섹션에 이동한 대표 4개 글을 세 화면 크기로 캡처했습니다. 화면 전체에 긴 문단이 표시되어도 기존 메모 구분·줄바꿈을 유지합니다.
- [measurements.json](measurements.json)과 [verify-depth.cjs](verify-depth.cjs)에 실제 검사 조건을 남겼습니다. 93개 자동 조건 통과는 모든 문장의 학술적 동료 심사나 실험 재현을 뜻하지 않습니다.
- 재캡처 중 기존 이미지 저장에 Windows 파일 오류가 한 번 발생했습니다. 기존 증거는 지우지 않고 실행별 새 캡처 폴더를 만들도록 검증 스크립트를 보완했습니다. 앱 콘텐츠 오류와 구분합니다.
