# 진행 상태 네 항목 후속 추가

사용자의 ‘제안한 상태도 우선 추가’ 요청에 따라 모집 취소·일시 중지·종료 확인 중·중단을 추가했습니다.
앞서 제안 단계였던 상태를 조회용 코드·필터·공통 배지·상세 설명·디자인 데모에 반영했습니다.
실제 프로젝트의 상태 전환이나 DB 상태 변경 기능은 이번 작업에 포함하지 않았습니다.

| 상태 | 의미 | 상세 예시 |
|---|---|---|
| 모집 취소 | 확정 전 연구자가 모집을 철회 | [보기](screens/detail-recruitment_canceled.png) |
| 일시 중지 | 참여자 합의로 잠시 중지하고 재개할 예정. 협업 관계 유지 | [보기](screens/detail-paused.png) |
| 종료 확인 중 | 종료 요청 후 참여자 확인을 기다림 | [보기](screens/detail-completion_pending.png) |
| 중단 | 시작한 협업을 목표를 마치지 못한 채 종료하기로 확정 | [보기](screens/detail-discontinued.png) |

일시 중지 예시는 데이터 접근 복구를 기다리며 중지·재개 예정일에 합의한 상황입니다.
중지 사유나 재개 예정일을 새로 입력·저장하는 폼을 만든 것은 아닙니다.
기존 공통 상태 목록을 확장하므로 목록과 상세, 검색 필터가 같은 이름을 사용합니다.

## 검증

- 프론트 관리자 테스트 22개·서버 운영 조회 테스트 10개 통과.
- 아홉 진행 상태 모두에 대해 데모 검색·기간/작성 상태 조합·표시 문구를 검사.
- 새 네 조회 코드의 서버 수용, 원천 상태가 없는 실제 모드의 빈 결과, 잘못된 코드 422 확인.
- TypeScript 타입 검사·변경 파일 ESLint·서버 Ruff 통과.
- 격리 복사본에서 Next.js 프로덕션 빌드·61개 정적 페이지 생성 통과.
- 기존 빌드 경고 3개(가입 완료 화면 미사용 변수, SiteHeader img 권고 2개) 유지.
- 1440/768/390px에서 페이지 가로 넘침 없음. 표는 작은 화면에서 내부 좌우 스크롤.
- 브라우저에서 새 네 상태와 완료의 필터·상세, 교차 검색·빈 결과·초기화·구형 API 호환 확인.
- 실제 API 대신 가상 응답 사용. 쓰기 0건·브라우저 실행 오류 0건. [결과](verification.json)
- 최초 캡처와 결과 파일은 보존하고 후속 결과를 이 폴더에 저장.

실데이터는 계속 연동 전/해당 없음으로 표시합니다. 실제 DB·로그인·업무 상태 전환·실기기·화면낭독기는 미검증입니다.
보고서 파일 네 개는 요청에 따라 읽거나 수정하지 않았습니다. 커밋·push·배포는 하지 않았습니다.
