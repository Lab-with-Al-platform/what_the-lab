# 목록 헤더 분리·인용 영역 축소 QA

검증일: 2026-10-09. 직전 에디토리얼 수정 위에 적용한 후속 변경입니다. 기존 캡처는 `../list-editorial-20261009/`에 보존했습니다.

## 변경과 이유

- 두 목록의 페이지 H1을 추천 콘텐츠 밖의 흰색 헤더로 이동했습니다. 페이지 이름과 추천 글 제목이 한 덩어리처럼 읽히지 않도록 배경·구분선·글자 크기를 나눴습니다.
- 추천 콘텐츠의 제목과 사진은 기존 그라데이션 연결을 유지했습니다. 카드 스타일과 필터·정렬·페이지네이션 로직은 변경하지 않았습니다.
- 연구 사례의 ‘연구자의 시선’은 인용 글자 크기, 내부 패딩, 문단 간격을 줄였습니다. 내용이 잘리지 않도록 고정 높이 없이 문장 길이에 따라 늘어납니다.
- 목록 컨테이너 끝 패딩과 공통 푸터의 바깥 여백이 중복되어 있던 부분을 제거했습니다. 다른 화면의 푸터는 변경하지 않았습니다.
- AI 트렌드에서는 ‘연구자의 시선’을 제거했습니다. 공통 컴포넌트의 `perspective`는 선택 데이터이며, 전달된 경우에만 인용 섹션을 출력합니다.
- 대체 콘텐츠는 승인 없이 추가하지 않았습니다. 향후 후보는 카드가 아닌 짧은 ‘연구 적용 체크포인트’ 텍스트 섹션입니다.
