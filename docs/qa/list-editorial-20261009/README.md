# 연구 사례·AI 트렌드 목록 디자인 QA

검증일: 2026-10-09

## 적용 범위

- `/cases`, `/trends`에 공통 에디토리얼 목록 구성을 적용했습니다.
- 상단은 왼쪽 제목에서 오른쪽 사진으로 자연스럽게 이어지는 그라데이션입니다. 모바일은 글 아래 사진으로 이어집니다.
- 카드 분류를 사진 아래로 옮기고, 제목·요약·날짜·읽는 시간의 간격을 정돈했습니다.
- ‘연구자의 시선’은 카드 박스 없이 인용문과 연구 현장 사진으로 유지했습니다. 사진은 예시 발언자의 실제 사진이 아닙니다.
- 하단 최근 콘텐츠 반복 목록은 제거했습니다. 별도 전문가 연결 섹션을 추가하지 않았습니다. 기존 공통 메뉴와 상세 페이지의 전문가 기능은 변경하지 않았습니다.
- 기존 Cursor 변경 및 앞선 필터 개선(줄바꿈, AM 코드 화면 숨김, 내부 코드 유지)을 보존했습니다.
- 실제 인터뷰·수집 콘텐츠·개인화 기능을 새로 구현하지 않았습니다.

## 시각 기준과 비교

P0 랜딩·암세포 상세 이미지의 색상, 서체, 여백과 공통 톤을 확인했습니다. 목록 정보 구조는 사용자가 승인한 새 시안과 이번 수정 요청을 우선했습니다. P0 이미지는 이 목록 화면 자체의 일대일 비교 대상이 아닙니다.

두 페이지의 세 크기 모두 가로 넘침이 없었고, 사진 로딩·텍스트 줄바꿈·하단 인용문을 확인했습니다. 캡처는 로컬 개발 서버의 전체 페이지이며 개발 도구 표시가 포함될 수 있습니다.

## 동작·정적 검증

- 연구 사례: 생성형 AI 선택 시 내부 URL `AM-04`와 1개 결과, 컴퓨터 비전 선택 시 5개 결과, 전체 복귀, 마지막 페이지 1개 결과를 확인했습니다. 분류 버튼에는 AM 코드가 표시되지 않습니다.
- 트렌드: LLM·에이전트 선택 시 3개 결과, 전체 복귀, 2페이지 6개 결과, 제목순 정렬의 첫 페이지 복귀를 확인했습니다.
- 상단 트렌드 링크가 `/trends/research-agent` 상세 화면으로 이동하는 것을 확인했습니다.
- 수정 파일 ESLint, TypeScript `--noEmit`, `git diff --check` 통과.
- `npm run build` 성공: 41개 정적 페이지 생성. 기존 `article-view.tsx`, `cover-art.tsx`의 `<img>` 최적화 권장 경고 2건은 유지했습니다.

## 미검증·경계

- 실제 모바일 기기, Safari·Firefox, 스크린리더, 백엔드 데이터 연동은 검증하지 않았습니다.
- 홈·전문가·상세의 기존 카드 마크업은 유지했지만, 이번 시각 QA는 위 두 목록에 한정됩니다.
- 커밋·push·외부 배포는 하지 않았습니다.

## 코드 이해 힌트

공통 `InsightBrowser`는 두 페이지의 ‘틀’이고, 각 `page.tsx`는 제목·본문·사진 주제를 전달합니다. CSS 그라데이션은 사진 위에 얇은 배경색 막을 씌우는 방식입니다. 목록 전용 카드 `editorial`을 분리해 홈과 상세의 기존 디자인이 함께 바뀌지 않도록 했습니다.
