# LAB TRUST | 100개 연쇄 질문·대응 근거 체크리스트
작성일 2026-10-31 · 기준: `feature/expert-search-dark-profile-first-20261031` / Draft PR #72

**읽는 법**: 질문은 단순 토론이 아니라 실제 소스/정책에 다시 연결한다. **구현**은 코드가 있다는 뜻이지 실사용 E2E가 완료됐다는 뜻이 아니다. '미구현/검증 필요'를 일부러 명시해 운영상 위험을 가리지 않는다.

**점수 원칙**: 공개 가능한 정상 종료 협업의 연구자 평가만 → 같은 연구자 최대 3건 → 3건/2명 미만 미산정 → 4개 항목 가중평균 + 소수 표본 완충 → 플라스크 0~100.

## 검증 시작점

1. [제품·수학·디자인·운영 전략](lab-trust-strategy-20261031.md)에서 정책을 확인한다.
2. `backend/tests/test_reputation_store.py`에서 영점/콜드스타트/가중치/권한을 검증한다.
3. CI 격리 PostgreSQL에서 `backend/tests/build_reputation_ci_query.py`가 **생산용 SQL을 그대로** 실행하고, 정상·미공개·중도 종료·숨김·한 평가자 4건을 검증한다.
4. `frontend/tests/lab-trust.test.cjs`로 수위 SVG와 로컬 시연 가드, 빈/오류 상태를 검증한다.
5. 실제 계정 E2E는 연구자 2명 이상과 서로 다른 완료 협업 3건이 필요하다. 테스트 데이터는 개인 개발 DB로 제한한다.
6. 운영 DB 적용·공개 평판 유통은 팀이 법무·개인정보·분쟁·공정성 정책을 합의하고 QA를 완료한 뒤 수행한다.

**판단**: 이번 브랜치의 P0는 '연구자 경험에 근거하는 파생 지수·설명 가능 플라스크'까지다. 독립 성과물 검증, 공모 탐지, 신원 검증, 개인별 평판 이의신청은 아직 완료되지 않았다.
