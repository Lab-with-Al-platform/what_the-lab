# 홈 소개·이용 안내 최종 검수

검증일: 2026-10-30(한국시간). 사용 한도 초기화 이후 예약 실행에서 미완료 검수를 이어갔습니다. 기존 Cursor/팀원 수정, 다른 작업의 미커밋 문서·쇼츠 자료는 수정하지 않았습니다.

## 1. 무엇을 구현했는가

- 기존 LabBridge 소개를 유지하고, 플랫폼 이용 안내·Discord 이용 안내를 같은 상단 프레임에 추가했습니다.
- 플랫폼 이용 안내: **인사이트 → 전문가 찾기 → 협업 매칭 → 프로젝트 진행**. 협업 요청·검토/협의·프로젝트 확정의 관계를 보조 설명으로 표시합니다. 인사이트를 꼭 읽어야 협업할 수 있다는 뜻은 아닙니다.
- Discord 이용 안내: 프로젝트 채널을 중심으로 챗봇과 Google Calendar가 연결되는 **소개용 개념도**입니다. 예시 대화와 연결선을 실제 메시지나 연동 성공 상태로 표시하지 않습니다.
- 상세 매뉴얼은 다른 팀원이 담당하고 URL이 아직 없으므로 ‘상세 매뉴얼 준비 중’ 문구만 표시합니다. 가짜 링크·FAQ 본문·외부 API 호출은 추가하지 않았습니다.
- 영상 재생이나 하루 방문 기록은 구현하지 않았습니다. [후속 영상 인계](../../planning/HOME_INTRO_VIDEO_HANDOFF_2026-10-30.md)에 ‘하루 첫 방문’, 일시정지·다시 보기·음소거·건너뛰기 요구와 정책 결정 대기를 보관했습니다.

## 2. 핵심 코드가 동작하는 방식

| 파일 | 역할 |
| --- | --- |
| `frontend/src/components/home-page.tsx` | 기존 홈과 연구 이미지를 유지하고 새 상단 컴포넌트를 조립 |
| `frontend/src/components/home-hero.tsx` | 화면 데이터·현재 순서·정지 상태와 사용자 조작 관리 |
| `frontend/src/components/home-guide-visuals.tsx` | 글자가 선명한 HTML/SVG 순서도·협업 공간 그래픽 |
| `frontend/src/components/home-hero.css` | 공통 토큰을 재사용한 홈 전용 배치·전환·반응형 |
| `frontend/tests/home-hero.test.cjs` | 콘텐츠·미정 링크·영상 범위·비활성 화면·정지 스타일 계약 검사 |

핵심 흐름을 위에서 아래로 읽으면 다음과 같습니다.

1. `HOME_SLIDES`는 세 화면의 짧은 소개 문구입니다. `activeIndex`는 지금 보이는 화면 번호입니다.
2. `isRunning`은 사용자가 멈추지 않았고, 마우스가 배너 밖에 있고, 탭이 보이며, 기기의 동작 줄이기가 꺼져 있을 때만 참입니다.
3. 진행 막대는 9초 동안 움직입니다. 막대의 `animationend`가 다음 화면을 선택합니다. 타이머와 진행 막대를 따로 두지 않아 서로 어긋나지 않습니다.
4. `selectSlide()`는 나머지 연산으로 마지막 다음은 처음, 처음 이전은 마지막으로 연결합니다.
5. `handleFocus()`는 키보드로 배너에 들어온 경우 멈춥니다. 다시 재생할지는 사용자가 정합니다.
6. 보이지 않는 두 화면은 `aria-hidden`·`inert`로 접근성과 키보드 탐색에서 제외합니다.
7. 세 화면은 같은 CSS Grid 칸을 공유합니다. 가장 긴 내용의 높이를 기준으로 삼아 전환할 때 아래 카드가 움직이지 않습니다.

사진을 새로 만들거나 화면 전체 폭으로 늘리지 않고 기존 `PageContainer`와 사진 최적화 경계를 재사용했습니다. 반응형 그래픽이 필요하므로 텍스트를 이미지 파일 안에 넣지 않았습니다.

## 3. 최종 캡처와 측정

P0 랜딩의 네이비·보라·화이트, 연구 사진, 공통 정렬선과 아래 탐색 카드 순서를 유지했습니다. 새 두 안내 화면은 2026-10-30 사용자 요청과 STYLE_GUIDE 16절을 기준으로 합니다. 구조가 추가된 부분을 P0와 픽셀 단위 일치한다고 주장하지 않습니다.

- 총 12개 크기/화면 조합에서 가로 넘침이 없고, 그래픽의 좌우 끝이 본문 프레임 안에 있었습니다. 2880px의 프레임 폭은 1400px입니다.

- 기존 캡처는 보존하고 최종 검수 파일은 `final-` 접두사로 별도 저장했습니다.
