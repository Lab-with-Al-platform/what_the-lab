# 홈 슬라이드 버튼 정렬

검증일: 2026-11-10 (한국시간)

## 해결한 문제

소개 화면은 제목 아래 로고가 있어 다른 두 안내 화면보다 내용이 깁니다. 기존에는 각 화면의 내용 전체를 세로 중앙에 놓아 버튼 위치가 달랐습니다.

가장 긴 내용을 기준으로 세 화면이 같은 버튼 행을 공유하도록 변경했습니다. 소개의 버튼 위치를 기준으로 플랫폼 FAQ와 Discord 준비 안내를 정렬하며, 버튼 너비는 문구에 맞게 유지합니다.

## 코드가 동작하는 방식

- `home-hero__message`: 영문 문구·제목·설명을 하나로 묶습니다. 제목과 설명의 기존 간격을 유지하기 위한 묶음입니다.
- `home-hero__slides`: 내용과 버튼의 두 행을 만듭니다.
- `grid-template-rows: subgrid`: 각 슬라이드가 부모의 행 높이를 함께 사용합니다. 표에서 여러 칸을 같은 가로 줄에 맞추는 것과 같습니다.
- `align-self: start`, `justify-self: start`: 버튼을 공통 행의 왼쪽 위에 두어 문구가 짧아도 가로로 늘어나지 않게 합니다.
- 1023px 이하에서는 내용 → 버튼 → 이미지의 세 행으로 재배치합니다.

고정 높이·임의 이동값·JavaScript 좌표 계산을 추가하지 않았습니다. 제목과 설명을 각각 늘려 정렬하면 두 문장 사이가 멀어지므로, 내용 묶음 아래의 여유 공간으로 버튼 위치를 맞췄습니다.

## 색상 의견

기존 P0 디자인 기준은 소개 문장보다 LabBridge를 색으로 강조합니다. 소개의 짙은 네이비 문구와 컬러 로고를 유지하고, 플랫폼·Discord 안내는 두 번째 문장을 보라색으로 강조하는 구성을 권장합니다. 이번 변경에서는 글자색·로고·버튼 크기·문구·목적지를 바꾸지 않았습니다.

## 실제 사용자 흐름

- 소개 버튼 클릭 후 `/#paths` 이동 확인.
- 플랫폼 FAQ 버튼 클릭 후 `/faq?category=workspace` 이동 및 ‘협업 공간·일정’ 선택 확인.
- 세 안내 화면 직접 선택 및 일시정지 동작 확인.
- 브라우저·서버에서 홈 및 FAQ 응답 200 확인.
- DB·인증·외부 API·환경 변수는 이 배치 변경의 경계 밖입니다.
