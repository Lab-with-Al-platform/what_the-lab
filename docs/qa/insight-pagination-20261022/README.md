# 관리자 표 — 최대 5개 페이지 번호

2026-10-22 사용자 요청: `1 / 7` 대신 `< 1 2 3 4 5 >` 형태로 이동하며 양 끝의 화살표는 비활성화.

- 관리자 표 아래 중앙 정렬. 기존 보라·밝은 배경·모서리 토큰을 재사용하고 현재 페이지는 테두리·배경·굵기와 `aria-current="page"`로 구별합니다.
- 현재 페이지 주변 번호를 최대 5개 표시합니다. 7페이지 목록의 처음은 1–5, 가운데는 2–6, 끝은 3–7입니다. 번호 클릭은 직접 이동, 화살표는 한 페이지씩 이동합니다.
- 처음에는 이전, 마지막에는 다음 화살표를 비활성화합니다. 결과가 0건이거나 한 페이지뿐이면 1번만 표시하고 양쪽 화살표가 비활성화됩니다. 조회 중에도 조작을 잠급니다.
- 검색·필터·메뉴 변경 시 기존의 1페이지 초기화 동작을 유지합니다. 한 페이지의 원고 수는 기존 6건입니다.
- `visiblePageNumbers()`는 페이지 수와 현재 위치로 번호 범위를 계산합니다. 전체 페이지 수보다 큰 번호나 중복 번호를 생성하지 않는 검사를 추가했습니다.

검증: 프론트 테스트 33개, TypeScript, 변경 파일 ESLint, `git diff --check` 통과. [브라우저 검사 10개](verification.json)는 실제 프론트에 GET-only 가상 응답을 연결해 번호 선택 후의 행 변경, 양 끝·한 페이지·빈 결과, 메뉴 초기화, 1440/768/390px 레이아웃과 터치 기기 44px 버튼을 확인했습니다. 실제 DB 요청·변경은 없습니다.
