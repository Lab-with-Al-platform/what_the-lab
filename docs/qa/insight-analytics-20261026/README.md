# 인사이트 조회수 화면 검증 — 2026-10-26

가상 API로 게시글 목록, 통계 탭, 글별 상세를 확인했습니다. 실제 Discord 로그인, 운영 DB 쓰기, 조회 수집 활성화, 원고 승인·게시는 하지 않았습니다.

## 톤

기존 관리자와 같은 좌측 4개 메뉴, 본문 패널, 얇은 하단 강조선 탭, 흰색 카드, 남색 숫자, 보라색은 활성 탭과 추이선에만 사용했습니다. 새 차트 라이브러리와 별도 최상위 메뉴는 없습니다. 캡처 왼쪽 아래의 N 표시는 Next.js 개발 표시이며 서비스 화면이 아닙니다.

## 조작으로 확인한 것

- 기간을 오늘로 바꾸면 주소의 `viewPreset`이 바뀝니다.
- 기간 조회수 정렬은 목록 API에 `order=period`로 가고, `scope=stats`는 보내지 않습니다.
- 0회와 미수집 `—`가 구분됩니다. 미게시 후보 편집창에는 통계 보기가 없습니다.
- 통계 검색 뒤에도 선택 기간 조회수 카드 숫자는 그대로입니다.
- 글별 상세에서 목록으로 돌아오면 통계 탭이 유지됩니다.
- 저장하지 않은 자동수집 설정은 이동 확인을 취소하면 그 탭에 남습니다.
- 가상 응답 외의 POST·PUT은 0건이고 페이지 오류는 0건이었습니다.

수치 기록은 [verification.json](verification.json)입니다.

## 실데이터와 데모

- 실데이터: 수집이 꺼져 있으면 카드는 수집 전이고 숫자를 0으로 만들지 않습니다. 게시글 목록의 숫자는 같은 집계 API를 한 번에 붙입니다.
- 데모: 통계 탭의 `디자인 데모`만 가상 글을 보여 줍니다. 주소는 `statsDemo=1`이며 서버로 보내지 않습니다. 운영 화면의 `demo=1`과는 따로입니다.

## 빌드·테스트

- 프론트 `tsc --noEmit`, 변경 파일 ESLint, 데모 합계 검사 통과.
- 백엔드 조회수 테스트와, 마이그레이션 사슬을 읽는 기존 작업공간 테스트 통과.
- 프로덕션 빌드는 `.env`를 복사하지 않은 임시 폴더에서 성공했습니다. 원본 `frontend/.next`는 덮어쓰지 않았습니다. `/admin/insights/statistics/[contentId]`가 빌드 결과에 포함되었습니다.

## 아직 하지 않은 것

- `INSIGHT_VIEWS_ENABLED`를 켜지 않았습니다. 원격 DB에 `20261026_07`을 적용하지 않았습니다.
- 이 폴더에는 `20261025_06` 파일이 없어 로컬 마이그레이션 부모는 `20261022_05`입니다. 적용 전에 부모를 `20261025_06`으로 바꿔야 합니다.
- 실제 공개 글에서 새로고침·뒤로가기가 조회 1회로 기록되는지는 브라우저 자동화 대신 서버 테스트로 확인했습니다. 자동화 브라우저는 수집을 보내지 않도록 되어 있습니다.
