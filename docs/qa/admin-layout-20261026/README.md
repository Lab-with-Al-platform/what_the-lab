# 관리자 공통 레이아웃·대시보드 디자인 개선

## 변경 결과

- 공통 좌측 사이드바: 운영 요약 / 회원 관리 / 연구 등록 / 인사이트 관리.
- 인사이트 하위 메뉴를 목록 패널 상단의 탭으로 이동: 전체 목록 / 수집후보 / 게시글 / 자동수집 설정.
- 제목 영역의 후보 버튼을 목록 도구로 이동하고 검색·초기화·새로고침과 크기·정렬을 통일.
- 운영 요약·회원·연구 등록에 요약 카드, 반응형 추이 그래프와 분포 막대를 배치.
- 연구 등록 과정 분석의 가상 단계·선택형 사유 예시를 제공. 실제 미수집 상태와 구별.
- 실데이터가 기본이며 '디자인 데모'를 선택하거나 해당 화면 주소에 `demo=1`을 붙이면 가상 자료로 평가.
- 데모는 운영 조회 권한이 있어야 표시되며 서버 저장·상태 변경·추적 활성화를 하지 않음.

## 화면 확인

기존 개발 서버에서 `/admin`을 열고 우측 상단의 **디자인 데모**를 선택합니다.
예: `/admin?demo=1&preset=30d`, `/admin/members?demo=1`, `/admin/projects?demo=1`.
등록 과정 예시는 `/admin/projects?demo=1&tab=abandonment`입니다.
실제 권한이 없는 계정에서는 주소에 `demo=1`을 넣어도 표시되지 않습니다.

인사이트 원고는 별도의 데모로 전환하지 않습니다. 그 화면의 등록·편집·승인 등은 기존 서버 기능입니다.

## 디자인 비교

관리자 전용 P0 시안은 없으므로 기존 랜딩·연구 상세 이미지의 공통 토큰을 재사용했습니다.
화이트·네이비·보라, 얇은 테두리, 제한된 그림자와 읽기 쉬운 고딕을 유지합니다.
사용자 첨부 이미지에서 지시한 목록 패널 위쪽을 탭 영역으로 바꾸고 이중 사이드바를 없앴습니다.
새 외부 차트·아이콘 패키지, 이미지·폰트 또는 테마 의존성을 설치하지 않았습니다.

- PC: 공통 좌측 메뉴 + 본문. 인사이트 검색·후보 조작은 한 도구 영역으로 정렬.
- 태블릿·모바일: 관리 메뉴를 상단으로 재배치. 모바일 인사이트 탭은 2열로 배치.
- 통계: 현재 상태 카드 → 선택 기간 추이·분포 → 관련 관리 목록 순서.
- 그래프는 컨테이너 너비를 측정해 축 글자 크기를 유지. 세부 값은 숨겨진 표를 펼쳐서도 확인 가능.
- 그래프 축·단위와 기간을 구분. 회원 생성은 가입 완료, 연구 생성은 최초 등록과 다름.

## 코드 흐름 — 학습용 안내

| 파일 | 책임과 이유 |
|---|---|
| `admin-shell.tsx` | 공통 메뉴·서버 접근 가능 영역 확인·데모 모드를 담당. 기존 인사이트 본문 iframe에는 메뉴를 넣지 않음 |
| `operations-frame.tsx` | 각 화면의 제목·설명을 담당. 공통 메뉴를 페이지마다 중복 생성하지 않음 |
| `admin-charts.tsx` | 요약 카드·기간 선택·추이·분포를 재사용. 그래프가 같은 값을 일관되게 표현하게 함 |
| `admin-demo.ts` | 고정된 가상 자료, 기간 집계·검색·페이지 이동을 제공. 네트워크·DB 쓰기가 없음 |
| `operations-summary/members/research.tsx` | 실제 API 계약은 유지하면서 화면 구성과 데모 자료 선택을 담당 |
| `insight-workspace.tsx` | 기존 원고 동작을 보존하고 탭·도구 위치만 재배치 |

API → 화면 상태 → 공통 카드/그래프/목록의 흐름입니다.
데모를 켜도 관리자 권한이 생기는 것은 아닙니다. 공통 프레임의 권한 확인 뒤에만 화면을 렌더링합니다.
서버의 기존 401/403 검사는 그대로이며 이번 작업에서 계정·역할·백엔드 권한은 변경하지 않았습니다.

## 검증

- TypeScript: `tsc --noEmit --incremental false` 통과.
- 변경한 프론트 파일 ESLint: 오류·경고 없음.
- `admin-dashboard.test.cjs` 신규 5개 + 기존 `insight-admin.test.cjs` 15개: 20/20 통과.
- 데모 기간 합계와 추이 합계, 가입 상태 합계, 검색·역할·기간·페이지 필터, 상세의 민감정보 제외를 검사.
- `verify.cjs`: 4화면 × 1440/768/390px에서 페이지 가로 넘침 없음.
- 브라우저에서 기간 변경·데모 유지·회원 검색·상세·등록 과정 탭을 확인.
- 인사이트 탭·검색 도구 표시·후보 가져오기/등록 모달·미저장 설정 이동 취소를 확인.
- 운영 전용·인사이트 전용·비로그인으로 메뉴/직접 접근/데모 접근을 검사.
- 원고 미리보기 iframe에 관리자 사이드바가 들어가지 않음을 검사.
- 모든 API는 Playwright 가상 응답으로 대체. 테스트 쓰기 0건, 브라우저 실행 오류 0건.
- 격리 소스 복사본에서 Next.js 프로덕션 빌드 및 61개 정적 페이지 생성 성공.
- 빌드의 기존 경고: 가입 완료 화면 미사용 변수 1건, SiteHeader의 img 권고 2건. 이번 UI 범위에서 수정하지 않음.

최종 브라우저 결과는 [verification.json](verification.json)에 기록합니다.
브라우저 검증은 가상 API 기반이며 실제 Discord 로그인·실제 DB 권한을 검증한 결과가 아닙니다.

### 별도로 남은 기존 검사 실패

추가 실행한 `insight-reading.test.cjs`에서 이번에 수정하지 않은 공개 인사이트 파일 검사 2건이 실패했습니다.

- 87행: `insight-browser.tsx`의 전용 표지 전달에 대한 정적 검사.
- 133행: 기존 치주골·MatterGen 콘텐츠의 보존 해시 검사.

전체 추가 실행은 40개 중 38개 통과·2개 실패입니다. 공개 콘텐츠·브라우저 파일을 이번 요청으로 덮어쓰거나
테스트 기대값을 바꿔 통과시키지 않았습니다. 새 관리자 전용 20개 검사와 구분해 보고합니다.

## 보존·미검증 범위

- 작업 전 수정 대상 7개 파일을 `tmp/admin-layout-20261026/before/`에 보존했습니다.
- 기존 팀 작업·백엔드·DB·공개 원고·사이트 헤더·전역 테마·의존성을 변경하지 않았습니다.
- 원본 `frontend/.next`를 빌드로 덮어쓰지 않고, `.env` 없는 격리 복사본에서 빌드·브라우저 검증했습니다.
- 실제 로그인·운영 DB 쓰기·회원 정지·원고 승인/게시·수집 실행·방문 추적·실기기 터치·화면낭독기·200% 확대는 미검증/미실행입니다.
- 서버 통계 수집이나 새 관리자 업무 기능을 구현한 작업이 아닙니다. 준비되지 않은 지표는 실데이터 모드에서 미수집 상태로 유지합니다.
- 커밋·push·PR·배포는 하지 않았습니다.

학습 힌트: 브라우저에서 데모를 선택해도 서버 권한이 바뀌지 않게 하는 이유와,
기간 계정 생성 그래프를 가입 완료 그래프라고 부르면 안 되는 이유를 함께 확인해 보세요.
