# 사례·트렌드 각 1편 본문 보강

확인일: 2026-10-16 (Asia/Seoul). 로컬 검토용 변경이며 서버 게시·DB 등록·커밋·푸시는 하지 않았다.

## 변경 범위

사용자가 사례와 트렌드에서 한 편씩 보강해 로컬에서 비교하도록 요청했다. 기능 개발은 보류하고 기존 `ArticleView`가 읽는 `frontend/src/lib/insights.ts`의 두 글만 수정했다. 본문 데이터만 확장했으며 공통 컴포넌트·스타일·인증·관리자·DB는 변경하지 않았다.

| 구분 | 로컬 주소 | 본문 문자 수 전 → 후 | 보강 후 구성 |
|---|---|---|---|
| AI 협업 사례 | http://localhost:3000/cases/periodontal-bone-loss-analysis | 1,195 → 4,006 | 10개 섹션, 26개 문단 |
| AI 트렌드 | http://localhost:3000/trends/mattergen-material-design | 1,160 → 4,401 | 9개 섹션, 27개 문단 |

문자 수는 본문 `paragraphs`만 합산한 JavaScript 문자열 길이다. 제목·요약·흐름 카드·연구 정보는 제외했다. 분량을 품질 점수로 삼지 않으며, 화면의 9분·10분은 편집 추정치라고 명시했다. 최초 게시 날짜는 유지하고 보강일을 별도 안내했다.

## 내용의 변화

- 사례: 자료 수와 과업별 사용량, 학습·테스트 분리와 별도 단계 평가, AI 검출과 규칙 계산의 분리, 지표의 의미·한계, 확인 가능한 공동 저자와 역할 추정의 구분, 연구 적용 전 준비 질문을 추가했다.
- 트렌드: 생성·예측·스크리닝의 차이, 학습 범위, 비교 실험의 조건, 합성 후보 선별과 실제 실험의 범위, 목표값 대비 최댓값과 평균값의 차이, 작은 시험 설계·실행 환경·재현성 주의점을 추가했다.
- 원문의 수행 사실과 LabBridge 해석·협업 제안을 문장 라벨로 구분했다. 추정한 인원·개발 기간·비용을 실제 연구의 사실로 넣지 않았다.
- 기존 요약 4항목·이미지·원문 링크·태그·관련 글과 글 주소는 유지했다. 이미지가 원 논문 도판이 아니라는 설명도 유지했다.
- 다른 28편은 내용 변경이 없다. 사례·트렌드 추가 생성이나 taxonomy 승인·변경은 하지 않았다.

## 근거와 확인 위치

### 협업 사례

Chang, H.-J., Lee, S.-J., Yong, T.-H. et al. (2020), *Deep Learning Hybrid Method to Automatically Diagnose Periodontal Bone Loss and Stage Periodontitis*, Scientific Reports 10, 7531.

- [원 논문](https://www.nature.com/articles/s41598-020-64509-z), [DOI](https://doi.org/10.1038/s41598-020-64509-z)
- Methods / Data preparation: 준비 영상 340장, 과업별 330·115·73장, 증강 전 90/10 분리, 검출에 쓰지 않은 단계 평가 영상 10장.
- Methods / Detection: 전문가의 정답 표시, 수정 Mask R-CNN·FPN·ResNet101, 후속 CAD 계산.
- Results / 표 2~4: 전체 단계 차이 평균 절댓값 0.25, 전체 상관계수 0.73, 전체 ICC 0.91. 검출 지표와 최종 분류 지표를 혼용하지 않았다.
- Discussion: 영상 확대·왜곡 때문에 절대 골 손실량을 제공하지 못하는 한계, 오류 사례, 기관 간 후속 평가 필요.
- Authors and Affiliations / Contributions: 공동 연구 참여는 확인되지만 소속에 따라 작업을 배타적으로 나눴다고 단정하지 않았다.
- 이 글은 의료 조언·최신 임상 지침·실제 제품의 임상 효용 검증이 아니다.

### AI 트렌드

Zeni, C., Pinsler, R., Zügner, D. et al. (2025), *A generative model for inorganic materials design*, Nature 639, 624–632. 최초 공개 2025-01-16.

- [원 논문](https://www.nature.com/articles/s41586-025-08628-5), [DOI](https://doi.org/10.1038/s41586-025-08628-5)
- Generating stable, diverse materials / 그림 2: Alex-MP-20의 607,683개 구조, SUN 정의, 학습 데이터 규모를 통제한 비교와 전체 성능의 구분.
- Experimental validation / 그림 6: 네 목표 각각 8,192개 생성, 필터 후 75개, 전문가 선정 4개 중 1개 합성. 합성 시료 TaCr₂O₆.
- 목표 체적 탄성률 200 GPa. 네 측정의 평균 158 ± 11 GPa와 최댓값 169 GPa를 구분했다. 초록의 목표 대비 20% 이내는 저자의 최선 추정인 최댓값에 해당한다. 직접 측정한 값과 푸아송비를 이용한 체적 탄성률 추정도 구분했다.
- Discussion: 평가 범위의 한계와 후속 실험의 필요.
- [Microsoft 공식 저장소](https://github.com/microsoft/mattergen): Installation의 Linux/CUDA 전제와 공개 체크포인트가 논문 당시 모델과 동일하지 않다는 안내. 실행 조건은 2026-10-16 열람 기준이며 모든 하드웨어의 실행을 보증하지 않는다.
- 후속 전체 연구와 비교한 최신 순위나 독립 재현 결과를 제시한 글은 아니다.

두 논문 모두 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 공개 조건을 확인했다. 한국어 요약·재구성임을 표시하고 원저자·논문·출처를 남겼다. 원문 도판을 복제하지 않았다.
