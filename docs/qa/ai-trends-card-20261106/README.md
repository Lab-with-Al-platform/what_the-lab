# 홈 AI 트렌드 카드 이미지 교체

## 목적과 변경 범위

사용자가 선택한 선명도 개선 데이터 스트림 이미지를 홈의 가운데 AI 트렌드 탐색 카드에 적용했습니다. 모니터 안의 UI 대신 흐르는 선·픽셀·파형으로 빠르게 변하는 AI 기술 흐름을 표현합니다.

- 시작 기준: 최신 `origin/develop`의 `56c4d2c`.
- 실행 코드 변경은 `frontend/src/components/home-page.tsx`의 이미지 경로 한 줄입니다.
- 새 자산: `frontend/public/generated/ai-trends-card-v2.webp`.
- 기존 `ai-trends-card-v1.jpg`, 양옆 카드 이미지, 문구·태그·링크·CSS·홈 소개 동작은 보존했습니다.
- 원본 시안과 관계없는 기존 미추적 파일은 이번 PR에 포함하지 않습니다.

## 이미지와 저장 방식

내장 이미지 생성 도구로 만든 사용자 승인 시안 `design/ai-trends-dynamic-stream-v4-sharp.png`를 시각적 재편집 없이 Sharp의 WebP 인코딩(`quality: 92`, `effort: 6`)으로 변환했습니다. 원본 시안은 로컬에 보존하며 서비스용 파일만 추가합니다.

| 항목 | 원본 PNG | 서비스 WebP |
|---|---:|---:|
| 크기 | 1774 × 887 | 1774 × 887 |
| 바이트 | 1,698,971 | 105,904 |

기존 Next Image의 반응형 크기 선택·최적화 및 흰색 그라데이션을 재사용합니다. 이 이미지는 장식용 배경이므로 기존 빈 대체 텍스트를 유지합니다. 연구 결과를 설명하는 도판이 아닙니다.

## 브라우저 검증

로컬 개발 서버 `http://127.0.0.1:3000/`에서 Chromium, DPR 1, 동작 줄이기 설정으로 동일 폭의 변경 전후 화면을 캡처했습니다. 폰트 로딩과 대상 이미지 디코딩 후 검사했습니다.

| 화면 폭 | 변경 전 | 변경 후 | 카드 크기(전후 동일) | 이미지 HTTP / 가로 넘침 / 실행 오류 |
|---|---|---|---|---|
| 1440 | [캡처](before-1440.png) | [캡처](after-1440.png) | 448 × 238.5, 3열 | 200 / 없음 / 없음 |
| 768 | [캡처](before-768.png) | [캡처](after-768.png) | 704 × 238.5, 1열 | 200 / 없음 / 없음 |
| 390 | [캡처](before-390.png) | [캡처](after-390.png) | 350 × 278.5, 1열 | 200 / 없음 / 없음 |

세 폭에서 새 이미지 주소와 실제 픽셀 로딩을 확인했습니다. 카드의 `/trends` 목적지와 네 개 태그 링크도 유지됩니다. 변경 후 세 캡처를 시각적으로 확인했고, 제목·설명·태그가 읽히며 양옆 카드와 정렬이 유지됩니다. 390px 섹션 캡처에는 기존 고정 헤더와 개발 도구 표시가 일부 겹치며, 중앙 AI 트렌드 카드 전체는 확인할 수 있습니다.

검증 스크립트는 `capture.cjs`, 원시 측정값은 `before.json` / `after.json`입니다. 스크립트는 테스트 패키지를 저장소에 추가하지 않고 외부 설치된 Playwright를 사용합니다.

```powershell
$env:PLAYWRIGHT_MODULE = '<설치된 playwright 폴더>'
$env:PLAYWRIGHT_BROWSERS_PATH = '<설치된 Chromium 캐시 폴더>'
node docs/qa/ai-trends-card-20261106/capture.cjs after
```

`before`는 기존 이미지 경로를 사용하는 변경 전 소스에서 실행합니다. 첫 실행에서는 샌드박스의 네트워크 제한 및 개발 서버 첫 컴파일 시간 때문에 캡처에 실패했으며, 서버 접근 환경과 로딩 대기 방식을 조정한 뒤 세 폭 모두 완료했습니다.

브라우저 검증은 로컬 개발 서버와 세 viewport 대상입니다. 실제 모바일 기기·다른 브라우저·운영 배포 화면·DPR 2 이상·줌 변경·장기 캐시는 별도로 확인하지 않았습니다. 이번 변경으로 백엔드·DB·인증·외부 API를 수정하거나 호출하지 않았습니다. 인사이트/전문가 목록의 전체 회귀 테스트는 이 작은 이미지 변경 범위에 포함하지 않았습니다.
