# LabBridges 로고·메인 영상 교체

## 사용자 승인과 범위

2026-11-26 사용자가 글자 간격과 전체 등장 효과를 수정한 v2를 승인하고 교체·배포를 요청했습니다.
영문 이름은 LabBridges, 한글은 랩브릿지, 심볼은 기존 글래스 브릿지입니다.
도메인 구입·DNS·AWS 서버 및 DB 설정 변경은 포함하지 않습니다.

## 변경

- 공용 헤더·푸터는 단일 아치, 메인 제목은 이중 아치를 유지한 LabBridges 로고로 교체.
- 영상은 이름 전체가 하나의 이미지·동일 등장 효과를 쓰는 승인된 v2로 교체.
- 영상 시작 전 포스터도 같은 버전의 브랜드 장면으로 교체.
- 파일명과 시청 기록의 버전을 바꿔 이전 자산 캐시·이전 시청 기록과 구분.
- 메인 안내의 브랜드명·접근성 이름·공통 페이지 제목을 LabBridges로 통일.
- 기존 파일과 원본은 보존. 로고 출력은 `frontend/scripts/export-labbridges-wordmarks.cjs`로 재현.

## 자산 확인

- 영상: 55초, 1280×720, 30fps, 1650프레임.
- 공개 폴더에 복사한 MP4의 SHA-256이 승인된 v2와 동일:
  `a7a3ac1261a7db5b8afc0c3cd58aaba14f9ca621567c2ef7e8f10991fd8c9408`.
- v2 제작 시 원본 AAC 압축 음원의 동일성을 확인했고, 이번 교체에서는 MP4를 재인코딩하지 않음.
- Bensound / Benjamin Tissot / 사용 코드 표시는 유지.
- 로고는 승인된 단일 마스터의 간격을 사용. 헤더는 기존 단일 아치 형태에 같은 s 윤곽을 같은 비율의 간격으로 배치.
