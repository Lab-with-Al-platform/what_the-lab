### 03. 통합검색·FAQ·게시판 연동

**Q021. 통합검색 데이터 원천은 무엇인가?**

- **판단:** 인사이트·FAQ는 자체 데이터, 전문가·게시판은 공개 API를 사용한다.

- **판단:** 공개 scope와 서버 visibility 필터를 사용하도록 설계돼 있다.
- **검증/추가 확인:** community 검색 필터·서버 권한 테스트

**Q023. 전문가 API 장애가 FAQ까지 막는가?**

- **검증/추가 확인:** global-search.test.cjs

**Q025. 검색어가 지나치게 길면?**

- **판단:** 프론트 정규화 및 API 길이 상한이 있으며 서버도 입력을 검증해야 한다.

**Q026. 검색 결과 클릭 시 올바른 원본으로 가는가?**
