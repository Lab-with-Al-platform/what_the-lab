## 남겨 두는 실제 운영 경계

정적 시안과 구현된 API, 가상 계정 검증과 실제 Discord OAuth, WASM PostgreSQL 호환 실행과 native Supabase 다중 서버 동시성은 서로 다른 증거입니다. 공개 출시 전에는 실제 HTTPS 도메인·OAuth callback·공통 DB 권한·개인정보 처리/보존 정책·백업/복구·실제 기기 접근성을 팀이 확인해야 합니다. 자동 배포나 실제 회원 권한 변경을 실행하지 않았습니다.
