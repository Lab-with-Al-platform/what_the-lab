## 보존한 현재 팀 기능

- 실제 공개 전문가 검색·taxonomy 확장·프로필 상세·포트폴리오·참여 이력.
- 내 연구/내 이력·기관 인증·공개 설정·프로필 사진 저장과 헤더 갱신.
- 직접 협업 요청·취소·만료·재전송·수락·거절·별도 시작과 요청관리.
- 상단 협업 알림·읽음·설정·조건부 Discord DM·guilds.join 재연결.
- 인사이트·사례·트렌드·관리자 승인 흐름과 원본 콘텐츠/디자인/택소노미 자료.
- 오늘 backend pyproject.toml/uv.lock, frontend package-lock.json 및 기존 migration/SQL 01~06 전체.

게시판 기능은 기존 회원·연구·요청·알림 자료를 자동 공개하지 않습니다. 기존 회원 is_admin만 게시판 운영 권한으로 사용합니다. INSIGHT_ADMIN_DISCORD_IDS를 게시판 관리자 권한으로 해석하지 않습니다. 현재 경로 B 직접 요청 흐름을 유지하며 공개 모집·마일스톤·완료/평가를 추가하지 않았습니다.
