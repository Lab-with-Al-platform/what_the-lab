# 자유게시판·FAQ 구현 안내

기준: 2026-10-26 업로드 `what_the-lab-develop (1)(1).zip` 766개 파일 + 이전 회의 분석 HTML + 게시판·FAQ V2. 최신 전문가 검색·직접 협업 요청·알림·프로필 설정과 통합했습니다. 현재 DB head는 `20261026_11`입니다. 게시판 개정은 `20261026_10`·`11`이고, `07`~`09`는 운영 조회입니다. 파일은 이미 제자리에 통합되어 있습니다. [현재 적용 안내](INSTALL_AND_QA.md)를 먼저 읽으세요.

회의 보고서 §10의 공개 글은 일반 이용자, 비공개 문의는 작성자·관리자에게 제공한다는 구분을 적용했습니다. 원 녹취는 이번 요청에 첨부되지 않았으므로 보고서에 기재된 약 53:03~54:02를 원 녹취에서 다시 검증했다고 주장하지 않습니다. 게시판을 MVP 테스트·문제 접수 채널로 시작한다는 목적을 유지합니다. 이번 사용자 요청은 과거 MVP 문서의 자유게시판 제외 조항에 대한 한정된 추가 구현 근거입니다.

인사이트의 `INSIGHT_ADMIN_DISCORD_IDS`는 게시판 관리자 권한을 부여하지 않습니다. 기존 공통 관리자 필드만 사용합니다. 실제 권한 부여는 이 패키지가 실행하지 않습니다.

## 기존 기능과 연결되는 부분

1. 헤더의 PC·모바일 공통 메뉴에 자유게시판과 FAQ를 추가했습니다. 메뉴가 길어져 접히는 기준을 `xl`로 조정했습니다. 기존 세 탐색 카드는 유지합니다.
2. 공개 사례·트렌드 하단의 `게시판에서 질문하기`가 해당 글의 slug를 작성 화면에 전달합니다. 관리자 본문 전용 미리보기에는 이 CTA를 넣지 않습니다.
3. 작성자가 선택한 공개 콘텐츠만 제목·링크로 연결합니다. 기존 내 연구·포트폴리오의 비공개 자료는 가져오지 않습니다.
4. 공개 게시글의 태그를 기존 `/experts?q=...` 검색으로 전달합니다. 자유 태그를 승인된 CAP 역량으로 등록하거나 자동 인증하지 않습니다.
5. 로그인은 기존 Discord JWT, DB는 기존 `DATABASE_URL`과 서버 연결 풀을 사용합니다. 새 유료 API·AI 모델·별도 인증 서비스가 없습니다.

## 데이터와 공개 범위

`community_private`에 posts, comments, reactions, bookmarks, notifications, reports, moderation_events, write_limits의 8개 표를 추가합니다. 사용자 FK는 기존 `public.users.user_id`를 참조합니다. 기존 회원·연구·인사이트 행은 수정하지 않습니다.

비공개 글은 공개 목록·검색·건수에서 제외합니다. 타인의 비공개 ID를 직접 입력해도 제목 대신 동일한 404를 반환합니다. 댓글·상태·공감·저장·신고 경로도 같은 접근 검사를 거칩니다. 공개 범위는 등록 후 변경하지 않아 댓글이 나중에 뜻하지 않게 공개되는 것을 막습니다.

응답은 `private, no-store`이며 상세 HTML·메타데이터에 실제 제목·본문을 넣지 않습니다. 사용자 본문은 일반 텍스트로 이스케이프하고 코드 블록만 `<pre><code>`로 표현합니다. 브라우저 localStorage에 문의 초안을 남기지 않습니다. 화면 내 링크·나가기·새로고침에서 미저장 내용을 안내합니다. 브라우저 뒤로가기를 완전히 차단하는 기능은 제공하지 않으므로 긴 글은 본인이 별도 보관하세요.

공유 DB와 여러 서버에서도 회원별 DB 행을 잠가 시간당 쓰기를 제한합니다. 새 글 10개/시간, 글·댓글 생성/수정·신규 공감/저장·신고 합계 120회/시간입니다. 삭제·해제·상태 변경·읽음·운영 조치는 이 한도 밖입니다. 중복 요청 token과 최신 version으로 등록 재시도·편집 충돌을 구분합니다. 채택된 댓글이 수정·삭제되면 해결 상태를 다시 열어 재확인을 받습니다.

## 운영 시 구분할 사항

구현·격리 테스트와 실제 운영 검증은 다릅니다. 실제 Supabase migration, PostgreSQL에서의 동시 작업·RLS 실호출, 실제 Discord 두 계정의 브라우저 E2E와 배포는 실행하지 않았습니다. FAQ는 현재 실제 전문가 검색·요청관리·상단 알림·Discord 연결·프로필 설정을 안내합니다. 게시판 답변 알림은 협업 알림 종과 별도이며 외부 DM으로 전송하지 않습니다. 캘린더 동기화·자동 협업 채널은 현재 제공 범위에 포함되지 않습니다.

자료 보존 기간·개인정보 처리방침·계정 삭제 정책은 운영팀이 실제 서비스 공개 전에 정합니다. 게시판의 화면 삭제는 원문을 지우고 접근을 차단하며, 타인의 댓글과 운영 이력의 물리 삭제를 자동 실행하지 않습니다.
