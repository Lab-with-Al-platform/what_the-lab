## 디자인 병합 이력

| 자료 | 의미 |
|---|---|
| [STYLE_GUIDE_ADDENDUM.md](design/STYLE_GUIDE_ADDENDUM.md) | 현재 스타일 가이드에 반영된 보강 제안 |

현재 시각 기준은 [STYLE_GUIDE](../design/STYLE_GUIDE.md)와 [화면별 명세](../design/SCREEN_DESIGN_SPECS.md)를 먼저 확인합니다. 보관 자료의 과거 경로·원본 패키지 설명은 당시 맥락이며, 파일이 이 저장소에 실제 있는지는 별도로 확인합니다.
