먼저 범위와 결정 로그를 읽습니다. 이후 팀 합의와 충돌하는 내용은 수정 근거를 남겨 동기화하며, 조사·기획 제안을 자동으로 확정 기능으로 취급하지 않습니다.

이동 전후에 기능 범위 내용은 바꾸지 않았습니다. 인사이트 정기 게시 등 이후 논의의 전체 제품 범위 반영 여부는 별도로 확인해야 합니다.
