# 06. 관리자 화면·콘텐츠·시각적 구현 지시

## 기존 화면 준수 규칙

- 새 공개 상세 UI를 별도 스타일로 만들지 않음. **현재 랜딩페이지와 사례 상세페이지의 확정된 디자인**을 기준으로 typography/grid/spacing/card/button/CTA를 재사용.
- 리스트 화면은 기존 레이아웃 참조, **상세 화면의 장식·컴포넌트를 리스트에 기계적으로 복제하지 않음**. 페이지 성격별 정보밀도 유지.
- 기존 상단 Blog/Insight 위치 및 네비게이션 임의 변경 금지.
- 미확인 Figma/시안에 없는 픽셀값이나 색을 '확정'이라 표시하지 않는다. 실제 CSS/디자인 시스템 확인해 명세 보완.
- 주요 상태 시각 구분에 색만 의존하지 않고 텍스트/아이콘 병행. 키보드 이동, label, focus, 반응형/한국어 줄바꿈 준수.

## IA

관리자 내 `연구사례 관리` 메뉴 → [대시보드 / 후보 목록 / 후보 상세 검토 / 실행 이력 / 설정(선택)]

### 대시보드

상단 통계: 신규 수집 수, 검토 대기, 근거 부족, 승인/예약, 최근 7일 게시, 최근 실패. 상태·기간별 필터. 수집 수동 실행 버튼은 이중 실행 잠금/확인과 한도 설명 포함. 차트보다 처리할 업무 목록 우선.

### 후보 목록

열: 제목(최대 2줄), 분야, 발표연도, DOI 존재, 12점, 증거상태, 키워드 상태, 수집일, 검토상태, 담당자. 검색(제목/DOI), 상태/분야/점수 범위, 정렬, 페이지네이션, 선택 시 상세 이동. 행 전체 클릭 및 독립 작업 버튼 중복 방지.

### 상세 검토

데스크톱 2열 제안: 좌측 편집 가능한 게시용 콘텐츠/Case Sheet, 우측 고정 출처·주장 근거·기술 키워드·승인 조건. 태블릿 이하 1열 탭(콘텐츠/근거/키워드/이력). 실제 배치·간격은 기존 디자인시스템 우선.

구성 순서:
1. 상태, 제목, DOI/공식 출처, 분야/연도/기관, 중복 의심 표시
2. 연구 문제 / 기존 병목 / AI 역할 / 연구자 역할 / 데이터 / 검증 / 성과 / 한계
3. 주장의 근거: claim별 표(주장, 원 출처, 위치, verified/needs_review/unsupported) — 출처 보기 링크
4. 점수 평가 7개와 자동/수동 판정 사유
5. 3계층 키워드 매핑(연구자용→AI분야→전문가 기술), 기존 Master ID와 신규 후보 분리
6. 공개 본문 미리보기(데스크톱/모바일) + 이미지 권리 점검
7. 편집 저장 → 승인 가능 조건 검사 → 승인/예약 또는 반려/추가 조사

이력 탭: 누가, 언제, 무엇을, 어떤 revision에서 승인/반려/수정했는지 표시. 오래된 승인 스냅샷은 read-only.

### 사용자 공개 인사이트 카드/상세

인사이트 카드: 실제 연구 문제 중심 제목, 분야/연도, 한줄 핵심 변화, 원 출처 표기, 1~2개 연구자용 활용 키워드. **자동 수집 결과를 AI 뉴스처럼 나열하지 않음.**

상세 섹션:
- [연구 문제] 무엇이 어려웠나
- [기존 방식의 병목] 시간/비용/정확도/탐색 한계
- [AI가 한 일] 실제 확인된 기술 활용
- [연구자가 한 일] 가설·데이터·실험·검증
- [어떤 데이터가 필요했나] 규모는 근거 있는 경우만
- [검증 결과] 수치마다 근거
- [한계 및 적용 조건]
- [관련 기술] 연구자용↔기술 분야↔전문가 Master ID
- [전문가 검색 CTA] 검증된 ID만 query parameter 전달
- [출처] DOI, 논문, 기관 프로젝트 및 작성/수정일

`scenario`는 '실제 연구 성과'처럼 보여주지 말고 명확히 **가상 협업 시나리오** 표시 및 공개 정책 승인 전 비공개.

## 액션 상세 UX

- 승인 버튼: evidence gate 통과 + verified Master ID + 필수 섹션 + 저장된 최신 revision일 때 활성화. 서버에서 재확인.
- 승인 확인 모달: 공개 제목/slug/게시 예약 시각/연결 기술 키워드/출처/수정본 revision 확인. 클릭 후 네트워크 실패 시 결과 조회 전 중복 제출 방지.
- 반려: 이유 필수; 재검토 가능 상태.
- 재분석: 덮어쓰기 대신 새로운 revision; 관리자가 수정한 본문은 자동으로 덮어쓰지 않음.
- 수동 보완: evidence 필요한 claim을 클릭하면 해당 섹션과 출처로 이동.
- Empty/Error/Skeleton 화면: 수집 0건, DOI 누락, 외부 API 장애, AI 분석 미완료, 키워드 매핑 0개 등 상황별 안내.

## 접근성/반응형/검증

360/768/1280px 대표 뷰포트에서 카드 깨짐·수평 스크롤·버튼 중첩 없는지; 제목/DOI/긴 전문용어 줄바꿈; 키보드 포커스; 상태 텍스트; 승인 모달 escape와 focus trap; 무권한 UI 은닉 및 서버 403; 기존 랜딩/상세 스크린샷 비교.

## 이미지 사용

출판사 논문 그림 자동 무단 복제 금지. 공식 허가/오픈 라이선스 확인한 이미지만 사용하며 저작자·라이선스/출처를 기록. 없으면 기존 디자인의 중립적 이미지/텍스트 카드 사용. 과학 데이터 시각화 생성 시 실제 데이터와 합성 그림임을 혼동시키지 않기.
