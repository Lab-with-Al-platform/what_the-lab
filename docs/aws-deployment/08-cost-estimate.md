## 2. 권장안 (시나리오 B: 월 $50.67) 세부 분석 및 추가 과금 리스크 방어

서울 리전 단가 정정으로 인해 시나리오 B의 예상 총액은 **약 $50.67**로 산출되며, 이는 목표치($50 내외)에 부합합니다.

### 2.1 4대 잠재 과금 리스크와 원천 차단책
1. **T4g CPU 크레딧 과금 위험**:
   - T4g 인스턴스가 '무제한(Unlimited) 모드'로 실행될 경우, CPU 사용률이 베이스라인(20%)을 초과할 때마다 **vCPU-시간당 $0.05**의 추가 요금이 부과됩니다.
   - **방어책**: EC2 생성 시 크레딧 사양을 **`Standard 모드` (CreditSpecification = standard)**로 강제 지정합니다. 크레딧 소진 시 성능이 베이스라인으로 쓰로틀링되나 추가 요금은 $0입니다.
2. **CloudFront 무료 구간과 아웃바운드 데이터 전송료 (Data Transfer Out)**:
   - **적용 조건 구분**: 본 비용 산정에서의 CloudFront $0.00은 월정액 유료 상품(CloudFront Security Savings Bundle 등)이 아니라, AWS 모든 계정에 영구 제공되는 **Always Free Tier (월 1TB 데이터 전송, 10,000,000건의 HTTP/HTTPS 요청, 2,000,000건의 CloudFront Functions 무료)** 조건을 적용한 것입니다.
   - **초과 위험 및 차단책**: 월 1TB(일일 약 33GB)를 초과할 경우 서울 리전 기준 GB당 $0.120의 종량제 요금이 부과되며, CloudFront를 거치지 않고 EC2에서 인터넷으로 직접 데이터가 나갈 경우 GB당 약 $0.126가 과금됩니다. 따라서 Nginx에서 정적 에셋 및 API 응답이 반드시 CloudFront 무료 티어 1TB 내에서 우선 소화되도록 구성합니다.
3. **EBS 스냅샷 누적 요금**:
   - 백업 스냅샷이 누적되면 GB당 월 $0.05가 발생합니다.
   - **방어책**: 수명주기(DLM)를 적용해 최근 7일 보관 후 자동 삭제합니다.
4. **도메인 등록/갱신 비용**:
   - Route 53 신규 도메인 구입 시 연 $12~$15(월 $1.00~$1.25 상당)가 추가 발생합니다.

### 2.2 $50 초과 시 즉각적인 비용 절감 옵션
1. **EC2를 `t4g.small`로 다운사이징 (시나리오 A 채택)**:
   - Supabase PostgreSQL을 외부 유지하면 EC2를 `t4g.small`($15.18/월)로 낮춰 **총비용을 즉시 $27.96/월(약 3.8만 원)으로 절감**할 수 있습니다. (단, Next.js 800MB 한도와 2GB RAM 환경에서의 실부하 안정성은 배포 전 검증 필요 `[UNVERIFIED]`).
2. **AI 프롬프트 캐싱 및 턴 수 제한**:
   - 대화 세션을 최근 5턴으로 제한하고 프롬프트 캐싱을 활성화하여 Bedrock 비용을 월 $3~$5 수준으로 억제합니다.
