- **micro + 서버 안 PostgreSQL**은 넣지 않았어요. 1GiB에 DB까지 올리면 메모리가 부족해요.
- **④는 가장 싸지만** 백업·복원을 직접 해야 하고, 서버가 멈추면 앱과 DB가 같이 멈춰요 (07쪽 DB 비교).
- ALB를 넣어도 **서버 1대로는 효과가 작아요.** 서버를 늘리려면 먼저 API와 예약 작업·봇을 나눠야 해요 ([15](15-instructor-feedback-20261110.md) 2절).
- **ALB는 "있으면 좋으니 금액을 확인해 보라"는 취지**였어요 ([15](15-instructor-feedback-20261110.md) #4). 확인 결과 월 약 $25.2라 ①·②보다 $25 정도 비싸져요.
- **팀 결정 (2026-11-10)**: **ALB는 나중으로 미뤄요.** 당분간 자체 테스트와 일부 사용자 대상 **베타 운영**이라 ①로 시작 → micro 부하 테스트 통과 시 ②. 사용자가 늘면 서버 분리 + ALB를 다시 검토해요 ([15](15-instructor-feedback-20261110.md) 2-2절). RDS 유지 여부(①② vs ④)는 아직 팀 결정 전이에요.

**S3로 옮긴다고 바로 싸지지는 않아요.** S3 자체 비용은 거의 0이지만 EC2 비용이 그대로면 총액도 그대로예요. 절약은 frontend가 빠져 EC2를 `t4g.micro`로 낮출 수 있을 때 생겨요.

## 4. 무료 혜택과 그 이후

- **신규 AWS 계정**: 가입 즉시 $100 크레딧 + 서비스 체험 시 최대 $100 추가, **최대 6개월**. Free 플랜 계정은 6개월이 지나거나 크레딧을 다 쓰면 자동으로 닫혀요 → 실제 서비스는 처음부터 **유료(Paid) 플랜**으로 시작하는 게 안전해요 `[CONFIRMED: aws.amazon.com/free 2026-11-06]`.
- **RDS 12개월 무료는 지금은 없어요 (2026-11-10 확인)**: 예전에는 새 계정에 RDS micro 12개월 무료가 있었지만, **2025-07-15 이전에 만든 계정**에만 해당해요 (AWS Legacy Free Tier) `[CONFIRMED: aws.amazon.com/rds/free]`. 지금 새 계정은 크레딧 방식이에요.
- **크레딧 사용 기간**: 유료(Paid) 플랜으로 바꾸면 남은 크레딧은 이후 청구서에 자동으로 쓰이고, **계정 생성 후 12개월**에 만료돼요 `[CONFIRMED: aws.amazon.com/free FAQ]`. 예: 크레딧 $200이면 월 $43.90 기준 약 4.5개월분이에요.
- **크레딧이 끝난 뒤에도 남는 무료**: CloudFront 월 1TB·1천만 요청, 인터넷 전송 월 100GB `[CONFIRMED]`. 위 비용표는 크레딧을 빼고 계산한 값이라 **크레딧이 끝난 뒤의 금액**이에요.

## 5. 과금 사고를 막는 장치

1. **AWS Budgets 경보**: 월 $40(예상), $50(실제) 두 단계 이메일 경보. 경보는 과금을 멈추지 않아요.
2. **T4g 크레딧 Standard 모드**: Unlimited면 CPU가 기준을 넘을 때 추가 요금이 붙어요. Standard는 추가 요금 대신 느려져요.
3. **CloudFront 경유 강제**: EC2에서 인터넷으로 직접 나가는 대용량 응답이 없게 해요. EC2→CloudFront 전송은 무료예요.
4. **로그는 서버에 10MB×3개만**: CloudWatch Logs로 보내면 Standard 수집 $0.76/GB `[CONFIRMED]`라 꼭 필요한 것만 보내요.
5. **멈춘 리소스 정리**: EC2를 멈춰도 Elastic IP·EBS·RDS 스토리지 요금은 계속 나와요. 안 쓰는 Elastic IP는 반납해요.

## 6. 비용을 더 줄이고 싶다면 (검토 후보)

- **CloudFront 정액제 Free 플랜**(월 $0, 초과 요금 없음, WAF·DDoS 보호·Route 53 DNS 등 포함으로 안내) — 플랜별 허용량은 `[UNVERIFIED]`.
- **1년 약정(Savings Plans / RDS 예약 인스턴스)**: 3~6개월 실측 뒤 서버 크기가 확정되면 검토. 할인율 `[UNVERIFIED]`.
- **EC2를 `t4g.micro`로 낮추기**: 프론트가 S3로 빠져 후보가 됐어요. 부하 테스트 통과 후 월 $7.59 절약.
- **RDS 대신 ②안**: 월 약 $2~3 절약되지만 DB 담당자의 백업·복원 부담이 커져요.
