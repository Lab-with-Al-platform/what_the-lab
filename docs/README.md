# Docs

제품 결정과 구현 협업에 필요한 문서를 모읍니다.

## 먼저 읽을 문서

1. [MVP_SCOPE.md](MVP_SCOPE.md): 지금 구현할 것과 미룰 것
2. [03_DECISION_LOG.md](03_DECISION_LOG.md): 팀의 주요 선택과 근거
3. [02_SCREEN_GUIDE.md](02_SCREEN_GUIDE.md): 화면·상태·사용자 흐름
4. [TEAM_WORKFLOW.md](TEAM_WORKFLOW.md): 브랜치와 PR 작업 방식
5. [STYLE_GUIDE.md](STYLE_GUIDE.md): 코드·UI 작성 기준

## 기존 자료

- `01_PRODUCT_STORY.pdf`: 제품 이야기와 방향
- `planning/`: 통합 기획 자료
- `research/`: 시장·사용자·콘텐츠 조사 자료

조사 자료의 제안은 참고 근거입니다. 현재 MVP 범위나 최신 팀 합의와 충돌하면 최신 팀 합의를 우선합니다.

## 문서 변경 규칙

- 결정이 바뀌면 코드보다 먼저 또는 같은 PR에서 관련 문서를 갱신합니다.
- 기존 자료를 삭제하지 말고, 새 결정의 날짜·이유·영향을 남깁니다.
- 구현되지 않은 기능을 완료된 기능처럼 표현하지 않습니다.
