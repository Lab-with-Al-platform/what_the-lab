# Backend

FastAPI 기반 API와 서버의 비즈니스 규칙을 담당합니다.

## 예정 책임

- 인증된 사용자와 역할 확인
- 연구자·AI 전문가 프로필 API
- 프로젝트 등록·탐색 API
- 협업 요청과 참여 신청의 서로 다른 상태 흐름
- 프로젝트 확정 이후 마일스톤·종료·평가
- 알림과 최소 관리자 기능

## 중요한 원칙

- 브라우저가 보낸 역할이나 소유권을 그대로 신뢰하지 않고 서버에서 확인합니다.
- 공개 응답 모델에는 개인 연락처를 넣지 않습니다.
- 서비스 역할 키는 서버에서만 사용합니다.
- 모집 정원과 최종 선택처럼 동시에 수정될 수 있는 작업은 데이터베이스 트랜잭션으로 보호합니다.
- API는 `/api/v1`처럼 버전을 포함한 경로를 사용합니다.

## 코드 구조를 만들 때의 기준

초기에는 이해하기 쉬운 단순 구조로 시작하고, 파일이 커질 때 `routers`, `schemas`, `services`, `repositories` 역할을 분리합니다. 복잡한 추상화보다 읽기 쉬운 함수와 명확한 타입 힌트를 우선합니다.
