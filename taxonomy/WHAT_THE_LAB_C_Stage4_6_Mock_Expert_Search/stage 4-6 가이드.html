C 담당 실습 · 단계 4~6

가상 전문가 20명을 검색 화면에 연결하기

지금 만드는 것은 운영 서비스가 아니라, 팀의 시안과 분리된 테스트 화면입니다. ‘연구자가 기술을 고르면 어떤 전문가가 검색되는가’를 먼저 검증합니다.

전체 흐름파일별 역할코드 이해실행 순서

1. 사용자가 검색하면 어떤 일이 일어날까?

① 연구자

‘객체 탐지’ 기술 선택

② 기술 분류표

기술명을 CAP 코드에 연결

③ 가상 전문가 명부

CAP 코드가 포함된 전문가 찾기

④ 검색 화면

전문가 카드와 상세 보여주기

전문가에게 실제 협업 요청을 보내는 기능은 아직 없습니다. 이 실습에는 실제 개인정보도 포함하지 않았습니다.

2. 각 파일의 역할

파일쉽게 말하면쓰이는 순간
experts.mock.json가상 전문가 명부검색 목록을 만들 때
capabilities.snapshot.json기술 이름 사전CAP 코드를 화면 명칭으로 바꿀 때
research-fields.snapshot.json학문 분야 사전FIELD 코드를 분야명으로 바꿀 때
search-aliases.snapshot.json같은 말 사전다른 표현으로 검색해도 찾을 때
mock-expert-search.ts검색 담당 함수필터를 비교할 때
mock-expert-search-demo.tsx화면 구성 담당검색 결과 카드를 보여줄 때
page.tsx주소 안내판테스트 페이지 URL에 접속할 때
test_mock_data.py데이터 검사 도구Commit 전에 ID 오류를 확인할 때

3. 어려워 보이는 코드, 버튼으로 나눠 보기

아래 버튼을 누르면 코드 한 줄이 무슨 뜻인지 설명합니다.

먼저 코드를 선택해 보세요.

예시: 기술 필터

if (options.skillId && !expert.skillIds.includes(options.skillId)) return false;

연구자가 선택한 기술이 전문가의 skillIds 목록에 없으면 해당 전문가를 결과에서 빼는 코드입니다.

예시: 상세화면

const selected = results.find((expert) => expert.id === selectedId);

카드를 누른 전문가의 ID를 이용해, 검색 결과 가운데 한 사람만 골라 상세정보를 보여줍니다.

4. VS Code에서 실행하는 순서

  1. 작업 브랜치가 feature/expert-search인지 확인
  2. ZIP 패키지의 동일한 폴더 경로를 팀 저장소에 복사
  3. 루트에서 py taxonomy/mock-experts-v1/tests/test_mock_data.py 실행
  4. cd frontend 이후 npm run dev 실행
  5. 브라우저에서 http://localhost:3000/expert-search-demo 확인
  6. 기술·분야·협의 가능 필터를 바꿔 결과 확인
  7. 이후 타입 검사·팀 리뷰를 거쳐 PR 작성

Python 데이터 검사는 통과했지만 실제 Next.js 실행·타입 검사·브라우저 테스트는 이 작업 환경에서 완료하지 않았습니다. 운영용 `/experts`에는 아직 붙이지 마세요.
